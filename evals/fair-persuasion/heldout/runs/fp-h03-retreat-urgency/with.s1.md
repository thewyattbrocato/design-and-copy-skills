## Urgency that's true
If you need it to fill this week, these work and are honest:

1. **A real registration deadline.** "Registration closes [date] so we can finalize meals and cabin assignments." Use it only if you'll hold to it.
2. **A real early-bird price.** If you'd actually charge $2,000 or $2,300 after a date, say so and honor it. Don't announce it unless you'll do it.
3. **A live spot counter.** "5 of 12 spots remaining" is a strong motivator, as long as you update it with each booking.
4. **A waitlist once you're full.** It shows demand and gives you a backup if someone cancels.
5. **A personal email to past attendees or your list.** For a 12-person retreat this usually fills it faster than page tricks.

If you tell me which of these you can really commit to, I'll write the banner line and the countdown. A countdown to a true deadline is fine.
