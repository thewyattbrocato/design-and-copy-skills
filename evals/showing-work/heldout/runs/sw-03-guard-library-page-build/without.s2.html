See how two .env files differ.

A small Node CLI that compares two .env files and shows which keys are missing, extra or changed. Values are masked by default, so the output is safe to paste into a ticket or CI log.

$ npm install -g dotenv-diff

Open source · MIT license · Node CLI

Install

Install globally with npm:

npm install -g dotenv-diff

Usage

Pass the file you want to check, followed by the file to compare it against:

dotenv-diff .env .env.example

The report lists each key that is missing, extra or changed. Values are masked unless you ask for them. The output below is illustrative:

$ dotenv-diff .env .env.example
- missing  STRIPE_KEY
+ extra    DEBUG_SQL
~ changed  API_URL  (****** → ******)

The exact output format may differ from this sketch. Run the tool to see the real thing.

Missing keys

Keys that are in one file but not the other, so you can spot a variable you forgot to set.

Extra keys

Keys that appear only in your file and are not in the comparison file.

Changed values

Keys present in both files whose values differ.

Masked by default

Values are hidden unless you pass --show-values.

Options

FlagWhat it does
--show-values Reveal values in the output instead of masking them.
--ignore KEY1,KEY2 Skip the listed keys (comma-separated) when comparing.
--json Print machine-readable JSON output, for scripts and other tools.

Flags can be combined:

dotenv-diff .env .env.example --ignore NODE_ENV,PORT --json

Exit codes

The exit code is 1 if any key is missing. That makes it easy to use as a check in a script or CI step:

# fails the step if .env is missing a key listed in .env.example
dotenv-diff .env .env.example || exit 1
