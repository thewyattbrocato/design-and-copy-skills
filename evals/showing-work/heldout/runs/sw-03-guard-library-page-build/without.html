See what's different between two .env files.

dotenv-diff is a small Node CLI that compares two .env files and shows which keys are missing, extra or changed. Values are masked by default, so the output is safe to read and paste.

Get started View on GitHub npm install -g dotenv-diff

What it does

  • Finds missing keys that are in the second file but not the first.
  • Finds extra keys that are in the first file but not the second.
  • Finds changed keys whose values differ between the files.
  • Masks values by default. Pass --show-values when you want to see them.
  • Works in scripts and CI with --json output and a non-zero exit code when keys are missing.

Usage

Pass the file you want to check, then the file to compare it against. A common case is checking your local .env against .env.example:

$ dotenv-diff .env .env.example

Example

The output below is illustrative. The exact formatting may differ from what your installed version prints.

$ dotenv-diff .env .env.example
missing  SENTRY_DSN
extra    DEBUG
changed  API_KEY  (values hidden)
$ echo $?
1

Options

FlagDescription
--show-valuesReveal values in the output. They are masked by default.
--ignore KEY1,KEY2Skip the listed keys, as a comma-separated list.
--jsonPrint machine-readable JSON instead of the default output.
 
$ dotenv-diff .env .env.example --ignore DEBUG,NODE_ENV --json

Exit codes

dotenv-diff exits with 1 if any key is missing, which makes it easy to use as a check in CI or a pre-commit hook. Otherwise it exits with 0.

$ dotenv-diff .env .env.example || echo "env files are out of sync"
