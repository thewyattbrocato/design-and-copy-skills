See what's different between two .env files.

dotenv-diff is a small Node CLI that compares two env files and reports which keys are missing, extra or changed. Values are masked by default, so the output is safe to paste into a ticket or a CI log.

$ npm install -g dotenv-diff
$ dotenv-diff .env .env.example
Get started View on GitHub

What it does

Env files drift. A key gets added locally and never makes it into the example file, or a new teammate's setup is missing a variable that production needs. dotenv-diff compares two files and groups the differences into three kinds:

  • Missing: a key that one file is expected to have and doesn't.
  • Extra: a key that appears in one file but not the other.
  • Changed: a key present in both files whose value differs.

Values are masked unless you ask to see them.

Install

Requires Node.js and npm. Install globally:

$ npm install -g dotenv-diff

Usage

Pass the two files to compare:

$ dotenv-diff .env .env.example

Common variations:

$ dotenv-diff .env .env.example --show-values
$ dotenv-diff .env .env.example --ignore NODE_ENV,DEBUG
$ dotenv-diff .env .env.example --json

Check the repository README for the exact output format of your installed version.

Flags

FlagDescription
--show-valuesReveal values instead of masking them. Be careful where you send the output.
--ignore KEY1,KEY2Comma-separated list of keys to skip in the comparison.
--jsonPrint machine-readable JSON, for scripts and other tools.

Exit code

dotenv-diff exits with 1 if any key is missing, which makes it usable as a check in CI or a pre-commit hook. Extra or changed keys are reported but don't cause a failure on their own.

$ dotenv-diff .env .env.example || echo "env files are out of sync"
