See what's different between your .env files.

dotenv-diff is a small Node CLI that compares two .env files and shows which keys are missing, extra or changed. Values are masked by default.

Get started View on GitHub 
$ dotenv-diff .env .env.example
- missing  STRIPE_KEY
+ extra    DEBUG_SQL
~ changed  DATABASE_URL  (values masked)

What it does

Missing keys

Keys present in one file but absent from the other.

Extra keys

Keys that exist only in the file you're comparing against.

Changed values

Keys in both files whose values differ.

Masked by default

Values are hidden unless you ask for them, so output is safer to paste or log.

Install

Requires Node.js. Install globally with npm:

npm install -g dotenv-diff

Usage

Pass the two files you want to compare:

dotenv-diff .env .env.example

Reveal values

dotenv-diff .env .env.example --show-values

Skip specific keys

dotenv-diff .env .env.example --ignore NODE_ENV,DEBUG

Machine-readable output

dotenv-diff .env .env.example --json

Options

FlagDescription
--show-valuesReveal values in the output. They are masked by default.
--ignore KEY1,KEY2Comma-separated list of keys to skip.
--jsonPrint machine-readable JSON output.

Exit codes

dotenv-diff exits with 1 if any key is missing, which makes it easy to use as a check in scripts and CI.

dotenv-diff .env .env.example || echo "Some keys are missing"
