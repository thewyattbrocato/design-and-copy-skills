Time Slot Picker

Stable v2.1 Replaces Dropdown Time Select

A grid of selectable appointment times, grouped by day. It helps patients scan availability across several days at once instead of opening a menu and scrolling a list.

Keyboard navigation

Arrow keys move through the grid. No mouse needed.

Screen reader announcements

Selecting a time announces the day and time.

Helpful empty state

When nothing is open, it offers the next date with openings.

Two densities

Comfortable and compact, for different layouts.

Keyboard and screen reader behavior

KeyAction
TabMoves focus into the grid (one tab stop) and back out again.
↑ ↓Previous or next time within the same day.
← →Same row in the previous or next day.
Home EndFirst or last time in the current day.
Enter SpaceSelects the focused time.
  • Each day is a labelled group, so screen readers announce the day when focus enters it.
  • Each time is a toggle button that exposes its pressed state.
  • Selecting a time updates a polite live region, for example “Selected Tuesday, November 3 at 9:30 AM.”
  • The empty state is announced when it appears, and its action names the date it will show.

Empty state

When no times are open for the days shown, the picker says so plainly and offers a single action: jump to the next date that has openings. Switch the demo to No times available to try it.

Usage

Do

  • Show several days at once so patients can compare.
  • Use the empty state’s next-date action instead of a dead end.
  • Default to comfortable density.

Don’t

  • Don’t use compact density on touch-first screens.
  • Don’t replace the empty state with a custom message that has no next step.
  • Don’t pair it with a dropdown for the same choice.

Migrating from Dropdown Time Select

The Time Slot Picker replaces the Dropdown Time Select for choosing an appointment time. The dropdown is superseded, so new work should use the picker, and existing screens should move over as they are updated.
