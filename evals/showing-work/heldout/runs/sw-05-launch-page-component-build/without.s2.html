Time Slot Picker

A grid of selectable appointment times, grouped by day. It helps patients scan availability at a glance and choose a time with a keyboard, a screen reader, or a finger.

What it does

Keyboard navigation

Arrow keys move through the grid. One tab stop for the whole picker.

Announces selection

Choosing a time is announced to screen readers with the full day, date and time.

Helpful empty state

When nothing is open, it offers the next date that has openings.

Two densities

Comfortable for primary flows, compact for tight layouts.

Live example

Keyboard and screen reader behavior

KeyAction
← →Move to the previous or next time within a day.
↑ ↓Move to the same position in the previous or next day (or the nearest time if that day has fewer).
Home EndJump to the first or last time in the current day.
Space EnterSelect the focused time.
TabEnter or leave the grid. Focus returns to the last selected or last focused time.

Each day is a labeled group and each time is a radio-style option, so only one can be selected. On selection, a polite live region announces, for example, “Selected Tuesday, November 3 at 9:30 AM.”

Set with density="comfortable | compact".

Empty state

If the visible range has no openings, the picker says so plainly and offers a single action: jump to the next date that does. Don’t leave patients with a blank grid.

Usage guidelines

 

  • Show only bookable times.
  • Group by day and label each day with weekday and date.
  • Always pair the picker with a visible confirmation of the chosen time.

 

  • Don’t use it for choosing a date range or free-form time entry.
  • Don’t hide the empty state behind an error message.
  • Don’t mix densities within one flow.

Migrating from Dropdown Time Select

Time Slot Picker replaces the Dropdown Time Select. Times are visible up front instead of hidden in a menu, and selection is announced to assistive tech. Plan to swap usages over to the new component; check the changelog for the v2.1 details.
