Set it as a few named styles with a right-aligned dot-leader tab for prices. Don't line prices up with spaces or a table.

**Sizes (A4, about 15–20 mm margins)**

| Role | Size | Setting |
|---|---|---|
| Restaurant name | 28–32 pt | Serif or display face, normal case, centred |
| Section heading (STARTERS, MAINS, PUDDINGS) | 12–13 pt | Capitals, tracked +1 pt (Character Spacing: Expanded), space before 20–24 pt, after 6–8 pt |
| Item name | 11 pt | Regular or medium weight |
| Item description | 9.5–10 pt | Regular, grey-brown rather than pale grey |
| Allergy and service note | 8.5–9 pt | Space above 18 pt |

That is five sizes, each with one job.

**Item layout**

- Add a right-aligned tab stop at the right margin with a dot leader. Each item is: name, tab, price. Put the description on the next line, using a line break (Shift+Enter) so it stays in the same paragraph.
- Prices should all have the same decimals and currency format: 4.50, 9.00, 12.50. Your copy has 4.5, 7.5 and 12.5, so I'd pad them to two decimals. Add £ or € if that's the currency. I haven't changed any wording.
- Use lining figures with the same width (tabular) if the font offers them. Most do by default.
- Leave the item text flush left and ragged right. Don't justify.

**Spacing**

- Between items: 6–8 pt.
- Between sections: 20–24 pt, roughly double the space before a heading as after it.
- Keep the heading with the first item (Keep with next).

**Setup in the word processor**

1. Set the page to A4 and the margins to about 18 mm.
2. Create paragraph styles: Restaurant name, Section, Item, Description, Note. Apply them rather than formatting each line by hand. Changing a style then updates the whole menu.
3. Add the tab stop in the Item style so every item shares it.
4. Use real italic or a real lighter weight for descriptions if you want them set apart. Don't use faux italic.
5. Once everything is in, check that the menu fills the page with comfortable space. If there's room, increase the space between items before increasing type sizes.

- The "each" on the oyster line can stay after the price ("4.50 each") or move into the description. Either reads fine.
