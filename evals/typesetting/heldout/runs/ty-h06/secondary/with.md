Set it as a single centred column, with a right-aligned price on each item's name line and the description underneath. Keep the type to about four sizes.

**Page and column**
- Margins of 20 mm on A4. Make the text column about 100 to 110 mm wide, centred. That gives roughly 55 to 65 characters per line, which is comfortable for short menu descriptions.
- Don't use dot leaders from name to price. Because the description sits under the name, leaders aren't needed, and they are the main thing that makes a menu look like a spreadsheet.

**Type sizes (print)**

| Role | Setting |
|---|---|
| Restaurant name | 20 to 24 pt, display or serif, tracked slightly |
| Section label (STARTERS, MAINS, PUDDINGS) | 9 to 10 pt, all caps, tracked +80 to +100 (about 0.08 to 0.1 em) |
| Item name | 11 to 12 pt, regular or semibold |
| Item description | 9.5 to 10 pt, regular, in a slightly softer colour |
| Price | Same size as the item name |
| Footer note | 8 to 8.5 pt |

- Use one family for everything, or at most two faces. Vary weight and size rather than adding fonts.
- Set item descriptions with about 13 to 14 pt of leading. Don't justify them; keep them left-aligned and ragged.

**Spacing**
- Space above each section label should be about double the space below it. For example, 18 to 22 pt above and 6 pt below.
- Between items within a section, use about 6 to 8 pt.
- Keep the name and its description together, and don't put a blank line between them.

**Prices**
- Use one format for every price, with two decimals: 4.50, 9.00, 12.50, 24.00, 7.50, 19.50. Mixed formats such as 4.5 and 24 look like a spreadsheet column.
- Place each price on the name line with a right-aligned tab stop set at the right edge of the text column. Right alignment keeps the decimals stacked even if the font's figures are proportional.
- Add the currency symbol once in the section label or the footer rather than on every price. I've assumed £, since the menu uses "puddings" and a discretionary service charge. Tell me if that's wrong.
- Keep the 12.5% in the footer as "12.5%" with a non-breaking space before the percent sign if your word processor supports it.

**Footer**
- Place the allergy line and the service charge note together at the bottom, centred, at 8 to 8.5 pt. Use a real italic face if you want italics, not a faux one.

**Steps in Word or similar**
1. Create paragraph styles: Section Label, Item Name, Item Description, Footer.
2. Set a right tab stop at the text-column edge on the Item Name style. Type the name, press Tab, then the price.
3. Set Space Before on the Section Label style to about twice the Space After.
4. Centre the header and footer paragraphs. Keep the body left-aligned.
5. Export to PDF with the fonts embedded before sending to print.

I've assumed a UK-style currency and a single colour print. If the menu will print in colour, use one accent colour for the section labels only.
