**Design tokens: naming + how to change them** 🎨

Please stop adding one-off colors and spacing values. Use an existing token, or propose one.

**Naming:** `category-role-variant-state`
Examples: `color-text-muted`, `color-bg-surface-hover`, `space-4`
- Name by **purpose**, not value (`color-text-danger`, not `color-red-500`)
- Spacing uses our scale only (`space-1` to `space-12`)

**Proposing a change or addition:**
1. Check the existing tokens first.
2. Open a ticket/PR with the token name, value, and where you'll use it.
3. Tag the design systems owner for review.
4. Once approved, merge it, then use it.

No token and no time to wait? Flag it in the PR so we can follow up.
