Hey team, we're getting a lot of one-off colors and spacing values, so let's stick to design tokens.

**Naming:** `category-role-variant`, e.g. `color-text-primary`, `color-bg-danger-subtle`, `space-4`. Use the token, never a raw hex or px value.

**Proposing a change or addition:**
1. Check the token list first. A close match probably already exists.
2. If nothing fits, open a PR that adds the token, with a short reason and where you're using it.
3. Tag @design-systems for review.

Please don't hardcode values in components. Thanks!
