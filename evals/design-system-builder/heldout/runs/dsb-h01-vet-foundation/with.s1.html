Design foundation

One set of decisions, made once. Tokens feed semantic roles, roles feed components, and every screen is built from those components. Calm, clear and warm. This is a clinic, so nothing here shouts.

Principles

Reassure, don't decorate

One teal accent, quiet neutrals. People booking care are often worried; the interface should feel steady.

Say it in words

Status always carries a label and glyph, never color alone. Errors say what to do next.

Easy to hit, easy to read

44px minimum targets, 16px body text, visible focus. Many users are on phones in waiting rooms.

Roles, not raw values

Components use --text-secondary, never --stone-600. That is what makes dark mode and rebrands cheap.

Type

System font stack, five roles. Pick the role, not a size. Body stays at 16px so form text never triggers mobile zoom.

Using and changing the system

Rules for builders

  1. Style with semantic roles and scale steps only. Never hex values or raw ramp tokens.
  2. Need something new? Use an existing component first. A pattern joins the system when a second screen needs it.
  3. A local one-off is allowed if it is marked /* exception: reason */.
  4. Every interactive piece ships with focus, disabled and error states and works by keyboard.
  5. Check any new color pairing in both themes before merging.
