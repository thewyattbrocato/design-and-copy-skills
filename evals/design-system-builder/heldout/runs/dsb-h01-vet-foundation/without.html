Design foundation · v1

Calm, clear, and careful.

Every screen in the Hollowbrook web app is built from the tokens and components on this page. Pet owners are often worried or in a hurry, so we favor plain language, generous spacing, large tap targets, and color that never carries meaning alone.

Reassuring

Soft greens and warm neutrals; no alarm colors unless something truly needs attention.

Trustworthy

Solid contrast, restrained shadows, and honest status messages that say what happens next.

Accessible

WCAG AA text contrast, 44px targets, visible focus rings, labels on every field.

01 · Color

Two layers: raw palette, then meaning

Components only use semantic tokens (--color-primary, --status-success-bg…). That lets us adjust the palette, or add a dark theme, in one place.

Each status is a trio — -bg, -border, -fg — chosen so the text passes AA on its own background.

02 · Typography

One system font stack, seven roles

system-ui keeps pages fast and familiar on every device. Use roles (.t-h2), not ad-hoc sizes. Body text never goes below 14px.

Writing guidance

  • Plain, warm, specific. “We’ll text you 24 hours before.”
  • Name the pet. “Biscuit’s visit” beats “the appointment”.
  • Errors explain the fix, never blame the user.
  • Emergency? Always show the clinic phone number, not a form.
