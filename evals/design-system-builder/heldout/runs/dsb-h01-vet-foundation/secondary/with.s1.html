Working rules

  • Use tokens only. No raw hex values or pixel sizes outside the token block.
  • Every interactive element needs a visible focus state and a 44px minimum target.
  • Status is never color alone: pair color with a label or icon.
  • Errors are written in plain language and say what to do next.
  • Clinical content uses calm, direct wording. Avoid exclamation marks and playful copy.
  • New components get added to this page before they ship in the app.
