Shared tokens, rules and components for the Hollowbrook web app. Build every screen from these pieces. If something you need is missing, add it here first, then use it.

Motion

Motion confirms an action; it never decorates. Animations turn off when the user prefers reduced motion.

  • Fast (120ms) for hover, press and color changes.
  • Base (200ms) for elevation and panel reveals.
  • Easing: --ease-standard for everything. No bounce or spring.

Voice and layout rules

Friendly and plain, never cute. We are a clinic: say what happens next, and avoid jargon in patient-facing text.

  • Plain language. "We could not book that time. Please choose another." Not "Error 409: slot unavailable."
  • Pet names are welcome. "Biscuit's visit" is fine. Keep the clinic name in the header, not in every sentence.
  • Every form field has a visible label. Placeholders are never used as labels.
  • Errors name the field and the fix, and move focus to the first problem.
  • Touch targets are at least 44px. Focus rings are always visible, never removed.
  • Content width is 1040px maximum, with 24px side padding.

Components

Each component has a small set of variants. Add a variant only when two real screens need it.
