Foundation and starter components

Every screen is built from these tokens and components. If a value you need is missing, add it here first, then use it. Don't hard-code colors, spacing, or radii in page code.

Color

Components use semantic roles. Palette values are only referenced by roles.

  • Action primary
    --color-action-primary
  • Surface accent
    --color-surface-accent
  • Surface page
    --color-surface-page
  • Text primary
    --color-text-primary
  • Status success
    --color-status-success-*

Rules for building new screens

  1. Use semantic color tokens only. Never use raw hex values or palette variables in components.
  2. Spacing, radius, and type come from the scales above. If a value is missing, propose it here first.
  3. Every interactive element needs a visible focus state and a 44px minimum touch target.
  4. Status is never shown by color alone. Pair color with a text label.
  5. Use plain, calm language. Avoid exclamation marks in medical or booking messages.
  6. Load no external fonts, images, scripts, or stylesheets. Everything ships inline.
