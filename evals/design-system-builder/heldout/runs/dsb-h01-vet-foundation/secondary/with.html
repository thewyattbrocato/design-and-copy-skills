Rules for building screens

These keep the app consistent as more people work on it.

  1. Use tokens only. No raw hex values, pixel spacing, or font names inside screens or components.
  2. Every control has a visible label. Placeholder text is never the only label.
  3. Status is never shown by color alone. Pair it with a word and an icon.
  4. Interactive targets are at least 44px tall. Focus rings stay visible and are never removed.
  5. One primary button per view. Use secondary or ghost buttons for other actions.
  6. Errors appear next to the field they describe, and the message says how to fix it.
  7. Missing a component? Add it to this page with its states before using it in a screen.
