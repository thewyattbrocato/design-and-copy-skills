Hollowbrook Vet Care

Design foundation · tokens, components, and a working sample

Principles

Every screen should feel calm, clear, and competent. Friendly in tone, precise in information. When in doubt, choose the option that makes a worried pet owner feel informed.

Clear over clever

Plain labels, specific dates, and one primary action per view.

Calm, never alarming

Use warm, reassuring language. Reserve red for things that need action now.

Accessible by default

Visible focus, labels on every input, and status that is never color-only.

Color

Teal anchors the brand and drives primary actions. Neutrals carry text and structure. Status colors are reserved for meaning and always appear with a label.

Using this foundation

  • Use tokens, never raw values. If you need a color, size, or space that isn't here, add a token first.
  • Name by role, not appearance. Write --color-danger-ink, not --red-dark.
  • Compose, don't restyle. Build screens from existing components. Add a modifier only if the variant will be reused.
  • Every input has a visible label. Hints and errors are linked with aria-describedby.
  • Every touch target is at least 44px. Keep focus rings visible. Never remove :focus-visible.
  • Status is never color alone. Pair every color with a word.
