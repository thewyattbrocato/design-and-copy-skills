Hollowbrook Vet Care

Design foundation

One set of decisions, made once. Warm enough to put an anxious pet owner at ease, plain enough to trust with a medical record.

Principles

Four rules we use to settle disagreements.

  • Calm before cleverPeople book visits when worried. Familiar patterns, no surprises, no decoration that competes with the task.
  • Warmth lives in color and wordingThe teal, the soft neutrals and plain-spoken copy carry the friendliness. Layouts and forms stay conventional.
  • Never color aloneEvery status pairs color with an icon or word. Every text pair passes contrast in every theme.
  • Use a token or ask for oneNo raw hex, no loose pixel values in screens. If nothing fits, propose a change (see Governance).

Governance

Light rules for a small team. Revisit when more than one squad is shipping.

Changing the system

Add a token or component when a second screen needs it. Not before.

Modify a value in tier 1 or 2 and every consumer changes. Check contrast in both themes first.

Deprecate by announcing it, naming the replacement, and keeping it for one release cycle before removing it.

Owner: [name your system owner]. Keep a changelog beside the tokens file.

In practice

Do write color: var(--color-text-secondary) and padding: var(--space-4).

Don’t write color:#5b6b67 or padding:15px, or reach for a --ref-* value in a component.

Don’t signal status with color alone, or build a second “card” that only differs by radius.
