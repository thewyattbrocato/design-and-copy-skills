Design foundation v1

Calm, clear, and careful with every patient.

This page is the single source of truth for how the Hollowbrook web app looks and behaves. Build every screen from the tokens and components below, so booking, records, and reminders feel like one product.

Principles

Our users are often worried about a pet. The interface should lower stress, never add to it.

  • Warm, but professional. Deep teal and soft sand, generous space, rounded corners. No cartoon styling, no exclamation-mark copy.
  • Never colour alone. Every status pairs colour with an icon and a word.
  • Tokens, not values. Components use semantic tokens (--text-muted), never hex codes or pixel values. Dark mode and future rebrands then come free.
  • Easy on every device. 44px minimum touch targets, visible focus rings, text at 17px by default, WCAG AA contrast.

Colour

Components use the semantic layer. Primitives exist only to define it. This page also adapts to dark mode through the same tokens.

Adding to the system

  • Need a new colour? Add a semantic token (e.g. --bg-overdue) with a dark-mode value. Don’t paste a hex into a component.
  • New component? Compose it from existing tokens, check keyboard focus, and make sure its states (hover, disabled, error) are covered.
  • Writing copy? Plain, kind, specific. Say what happened and what to do next (“Please choose which pet is coming in”, not “Invalid input”).
