Backups / Restoring a snapshot

Restoring a snapshot

A snapshot is only useful if you can get your files back. This page walks through finding a snapshot, previewing a restore, and writing the files to disk.

About 5 minutes · Applies to Brine 2.x · Last updated 12 September 2026

Before you start

  • Brine 2.1 or later is installed (brine --version).
  • You can reach the repository and have its passphrase.
  • The target location has enough free space for the files you restore.

  1. List the available snapshots

    Each snapshot has a short ID, a timestamp, and the paths it covers. Note the ID of the one you want.

    $ brine snapshots --repo ~/backups/brine-repo
ID        TIME                  HOST       PATHS
a41f9c02  2026-10-12 02:00:04   laptop     /Users/sam
7be03d5e  2026-10-13 02:00:03   laptop     /Users/sam
c90d1a77  2026-10-14 02:00:05   laptop     /Users/sam

  2. Preview what will be restored

    Run the restore with --dry-run first. Brine prints every file it would write and changes nothing on disk.

    $ brine restore c90d1a77 --target ~/restore-test --dry-run
Would restore 1,284 files (3.2 GiB) to /Users/sam/restore-test

  3. Restore to a separate directory

    Enter the passphrase when prompted. To restore only part of a snapshot, add one or more --include patterns.

    $ brine restore c90d1a77 --target ~/restore-test \
    --include "Documents/**"
Enter repository passphrase: ········
Restored 212 files (418 MiB) in 14s

  4. Verify the result

    Compare the restored files against the snapshot's recorded checksums. Brine exits with code 0 when everything matches.

    $ brine verify c90d1a77 --target ~/restore-test
212 files checked, 0 mismatches
Restoring over existing files

If you set --target to a directory that already holds files, Brine overwrites any file with the same path. Overwritten files cannot be recovered from Brine.

Restore to an empty directory first, then copy across what you need. If you must restore in place, pass --no-overwrite to skip files that already exist.
