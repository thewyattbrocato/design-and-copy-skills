**Pick: a modular grid, built on a single text column.** Use a column grid, but set the long text at one capped measure. A narrow column on its own is too monotonous for six mixed sections. Two-column text across every page makes stories and stats compete, and it breaks badly around pull-outs.

**Structure**
- **Grid:** A 6-column grid on a print page, or the same grid reflowing on screen. Body text takes 3–4 columns, about 60–70 characters per line. That leaves a narrow side column. It holds captions, source notes, small stats and pull quotes. Long text gets one reading edge, and everything else hangs off it.
- **Pacing:** Don't give all six sections the same template. Vary them by content:
  - **Long-text sections:** one text column plus the side column.
  - **Story sections:** an open layout with a large photo, a wide pull quote and generous white space. Make one of these the loud section, such as the opener or the main beneficiary story.
  - **Stats section:** a full-width band that breaks from the text edge.
- **Grid breaks:** Break the grid only for a named job: a full-bleed photo, a pull quote hanging into the margin, or the stats band. Don't break it any other way.

**Handling the stats**
1. **Lead with 3–4 headline numbers.** Examples are children reached, books distributed and volunteer hours. Set them large in a full-width band. Each gets one number, a short plain-language label and a year-on-year comparison.
2. **Keep the rest in context.** Put smaller supporting stats in the side column beside the paragraph they support. A number sits next to the claim it backs up.
3. **Use charts sparingly.** Chart only trends or comparisons, such as reading-level progress over time. Use simple bars or lines, direct labels, one or two colours from the brand palette, and no decoration. Give a single number a big figure, not a chart.
4. **Humanise them.** Pair at least one stat per section with a person or story ("1 of the 4,200 children…"). That ties the numbers to the stories.
5. **Keep them consistent.** Use one numeral style, one label style, and one unit and rounding convention throughout. Every stat has a year and a source line.

**Check before finalising**
- Test the worst cases: the longest section, a stat with a long label, and a story without a photo.
- Read the single-column stacked order (for web or PDF on phones). The headline stats should still come early, and the side-column notes should land right after the text they belong to.
