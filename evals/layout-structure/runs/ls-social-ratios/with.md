**Recompose per size.** Cropping one graphic won't work, because the three formats have different shapes.

- **1200×630** is wide, so put the logo and name side by side with the benefit line.
- **1080×1080** is square, so use a centered or stacked layout.
- **1080×1920** is tall. Cropping would cut content, and platform UI covers the top and bottom roughly 250px, so keep key content in the middle.

Keep a shared system across all three: the same type, colors, logo treatment, and copy hierarchy (name, then benefit, then date). Build one master template with those parts, then rearrange them for each canvas.

Cropping is only reasonable for a purely decorative background. Even then, check that the text and logo fit each size.
