**Recompose per size.** Cropping one graphic fails because the three formats have different shapes and jobs.

- **1200x630** is wide, so the layout runs horizontally. It's often shown small, so the product name needs to be large.
- **1080x1080** is square. Stack the elements in a centered layout.
- **1080x1920** is tall. Platform UI covers the top and bottom, so keep the key content in the middle safe zone.

A crop will cut off the logo or the date, or leave the text too small.

Share the same assets across all three: the palette, typeface, wording, and logo. Build the layout once, then adapt it for each size. This keeps the brand consistent with little extra work.
