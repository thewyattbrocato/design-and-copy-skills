Twelve columns is a planning lattice, not a rule that fits every page. It fails in these cases:

- **Reading pages.** Text should run about 45–75 characters per line. A 12-column grid invites paragraphs spanning 8–10 columns, which is too wide to read comfortably. Set the measure first, then derive the columns.
- **Uniform grids.** Catalogs and listings work better as equal cells that wrap. A fixed 12-column grid forces awkward breakpoints, and 12 doesn't divide into 5 or 7.
- **Content-sized columns.** A sidebar or outline should be as wide as what it holds, not "3 of 12."
- **Fixed formats.** Slides, posters and social cards need exact unit arithmetic for their own ratios.
- **Wide data tools.** These need full width and frozen columns, not a column count.

If your design system already provides a 12-column layout, use it, but still cap the text blocks. Choose the structure per page from its material: reading column, wrapping grid, bands or app shell.
