API reference / Refunds

Create a refund

Return funds from a captured payment to the customer's original payment method. You can refund a payment in full or in part, and issue several partial refunds until the captured amount is used up.

POST https://api.ledgerline.example/v1/refunds Requires a secret key

Refunds are created in the pending state and usually settle within 5–10 business days, depending on the customer's bank. Listen for the refund.succeeded or refund.failed webhook rather than polling.

Parameters

Send parameters as a JSON body. Include an Idempotency-Key header so a retried request never refunds twice.

  • paymentstringRequired

    ID of the captured payment to refund, for example pay_8Kf2nQ. Payments that are uncaptured or already fully refunded return an error.

  • amountintegerOptional

    Amount to refund, in the smallest currency unit (cents for USD). Defaults to the full amount still refundable on the payment. It can't exceed that remainder.

  • reasonenumOptional

    Why the refund is being issued. Shown in the dashboard and used in reporting.

    requested_by_customerduplicatefraudulentother
  • metadataobjectOptional

    Up to 20 string key-value pairs for your own records, such as an order or support ticket number. Keys are limited to 40 characters and values to 500.

  • notify_customerbooleanOptional · default true

    Send the customer an email receipt when the refund succeeds. Set to false if you send your own.

Code samples

Refund $12.50 from a payment because the customer returned an item.

cURL

cURLNode.js
curl https://api.ledgerline.example/v1/refunds \
  -H "Authorization: Bearer $LEDGERLINE_SECRET_KEY" \
  -H "Idempotency-Key: refund-order-10442" \
  -H "Content-Type: application/json" \
  -d '{
    "payment": "pay_8Kf2nQ",
    "amount": 1250,
    "reason": "requested_by_customer",
    "metadata": { "order_id": "10442" }
  }'

Node.js

cURLNode.js
import { Ledgerline } from "@ledgerline/node";

const ledgerline = new Ledgerline(process.env.LEDGERLINE_SECRET_KEY);

const refund = await ledgerline.refunds.create(
  {
    payment: "pay_8Kf2nQ",
    amount: 1250,
    reason: "requested_by_customer",
    metadata: { order_id: "10442" },
  },
  { idempotencyKey: "refund-order-10442" }
);

console.log(refund.status); // "pending"

Response

Returns the refund object with status 201 Created. If the request fails, the API returns an error object; the most common are payment_not_captured and amount_exceeds_refundable.

{
  "id": "re_3Tq9xA",
  "object": "refund",
  "payment": "pay_8Kf2nQ",
  "amount": 1250,
  "currency": "usd",
  "status": "pending",
  "reason": "requested_by_customer",
  "metadata": { "order_id": "10442" },
  "created_at": "2026-10-04T15:21:09Z"
}
