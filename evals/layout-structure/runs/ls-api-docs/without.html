API reference/Refunds/Create

Create a refund

POSThttps://api.ledgerline.example/v1/refunds

Return funds from a captured payment to the customer's original payment method. You can refund a payment in full or in part, and issue several partial refunds until the payment's remaining balance reaches zero.

Refunds start in the pending state and usually settle within 5–10 business days, depending on the card network or bank. Ledgerline sends a refund.succeeded or refund.failed webhook when the outcome is known.

Heads up: refunds can't be edited once created. To stop one that is still pending, use Cancel a refund.

Parameters

payment_idstringrequired

The ID of the captured payment to refund, for example pay_8Kd2mQ41xT.

amountintegeroptional

Amount to refund in the smallest currency unit (cents for USD). Defaults to the full remaining balance. Must not exceed what is still refundable.

reasonenumoptional

One of duplicate, fraudulent, requested_by_customer, or other. Used in reporting and shown on the customer's statement where supported.

metadataobjectoptional

Up to 20 key-value string pairs for your own records. Keys are limited to 40 characters and values to 500.

notify_customerbooleanoptional

When true, Ledgerline emails the customer a receipt. Defaults to false.

Send an Idempotency-Key header to safely retry requests without creating duplicate refunds.

Examples

Request

cURLPOST /v1/refunds
curl https://api.ledgerline.example/v1/refunds \
  -H "Authorization: Bearer $LEDGERLINE_SECRET_KEY" \
  -H "Idempotency-Key: 6f1c2a9e-order-4417" \
  -H "Content-Type: application/json" \
  -d '{
    "payment_id": "pay_8Kd2mQ41xT",
    "amount": 2500,
    "reason": "requested_by_customer",
    "metadata": { "order": "4417" }
  }'

Response

201 Createdapplication/json
{
  "id": "re_3Wq90vLcA7",
  "object": "refund",
  "payment_id": "pay_8Kd2mQ41xT",
  "amount": 2500,
  "currency": "usd",
  "status": "pending",
  "reason": "requested_by_customer",
  "metadata": { "order": "4417" },
  "created_at": "2026-10-04T14:22:08Z"
}

Errors

409 payment_not_captured is returned if the payment hasn't been captured yet. 422 amount_exceeds_balance is returned when amount is larger than the remaining refundable balance.
