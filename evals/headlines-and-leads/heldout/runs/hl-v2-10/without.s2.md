**Headline options**

1. **Borrow the ladder. Skip the garage.** (Keep this. It's already tight and the rhythm works.)
2. Alt: **Don't buy the drill. Borrow it.**

**Subhead (tightened)**

> 300+ tools, $5 a month. Join the Eastgate Tool Library and borrow drills, ladders, and more. All you need is a library card and a neighborhood ZIP code.

**Punchier version**

> Drills, ladders, and 300+ other tools for $5 a month. Just bring a library card and a neighborhood ZIP code.

**Why these changes**
- Leads with the offer (the number and price) instead of "Join the library and..."
- "Members only need" is wordy. "All you need" or "Just bring" is quicker and friendlier.
- "Neighborhood ZIP code" is shorter than "a ZIP code in the neighborhood."
- The punchier version drops the library name, so make sure it appears elsewhere in the hero, such as the nav, logo, or button ("Join Eastgate Tool Library").

If you want a different tone, here's a more playful take:

> **Borrow the ladder. Skip the garage.**
> Drills, ladders, and 300+ more tools, $5 a month. Bring a library card and a neighborhood ZIP. We'll supply the tools.

I'd go with the punchier version plus a "Join Eastgate Tool Library" button.
