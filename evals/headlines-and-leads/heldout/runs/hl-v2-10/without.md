Your headline is already strong, so I'd keep it. The subhead is where the room is: "Members only need" is wordy, and "a ZIP code in the neighborhood" reads awkwardly.

**Option 1: tight**
> **Borrow the ladder. Skip the garage.**
> Join the Eastgate Tool Library: 300+ tools, $5 a month. All you need is a library card and an Eastgate ZIP code.

**Option 2: punchier**
> **Borrow the ladder. Skip the garage.**
> Drills, ladders, and 300+ more tools for $5 a month. Just bring a library card and your Eastgate ZIP.

**Option 3: more playful**
> **Borrow the ladder. Skip the garage.**
> 300+ tools. $5 a month. One library card. Join the Eastgate Tool Library and stop buying things you'll use once.

Notes:
- **Option 1** is the safest. It keeps the nonprofit's name up front and drops the filler.
- **Option 2** has the most rhythm, but "Eastgate ZIP" assumes people know which ZIPs qualify. If that's unclear, link to the eligibility list near the button.
- **Option 3** has the most personality. The "stop buying things you'll use once" line is a claim about the reader, so check that it fits your tone.
- I wrote "an Eastgate ZIP code" in a couple of places. If the eligible ZIPs don't all carry the Eastgate name, use "a neighborhood ZIP code" instead.

If you'd like a mention of the nonprofit status, "Eastgate's nonprofit tool library" works well in the subhead. It builds trust without adding much length.
