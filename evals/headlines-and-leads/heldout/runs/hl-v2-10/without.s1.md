**Subhead:** Borrow drills, ladders, and 300+ other tools for $5 a month. All you need is a library card and a neighborhood ZIP code.

**What changed**
- I dropped "Join the Eastgate Tool Library and," since the site and CTA already say who you are. The subhead now starts with the benefit.
- "Members only need" became "All you need is." That's shorter and more direct, and it speaks to the reader.
- "A ZIP code in the neighborhood" became "a neighborhood ZIP code."

**Punchier alternates for the subhead**
- *Shorter:* 300+ tools, $5 a month. Just bring a library card and a neighborhood ZIP code.
- *More energy:* Drills, ladders, and 300+ other tools are yours to borrow for $5 a month. Bring a library card and a neighborhood ZIP code.
- *Nonprofit angle:* Eastgate's nonprofit tool library lends drills, ladders, and 300+ more for $5 a month. All you need is a library card and a neighborhood ZIP code.

If the nonprofit status builds trust with your audience, I'd use the third one. If you want it as lean as possible, use the first.
