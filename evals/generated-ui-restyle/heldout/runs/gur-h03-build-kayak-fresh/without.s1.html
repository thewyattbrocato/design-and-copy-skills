Saltrow Built by two paddlers · Gannet Sound
Trip log + tide & current windows

Know when to go out. Know when to be back.

Saltrow is a trip log for sea kayakers. It also shows the tide and current windows for the launch spots you save, so you can see when a paddle makes sense and when you need to be off the water.

iPhone and Android, launching in the spring. One email when it's out, nothing else.

What it does

Three jobs, done without fuss.

  1. 01

    Log the trip

    Launch spot, route, distance, conditions, and who you paddled with. Written down the same way every time, so next season you can look back and see what a day was actually like.

  2. 02

    See the window

    Save the launch spots you use. Saltrow shows the tide and current for each one, so you can see when the water is moving gently and when it isn't.

  3. 03

    Plan the return

    The window has two ends. Saltrow shows both, so the time you need to be back is part of the plan before you leave the beach, not something you work out halfway across the sound.
