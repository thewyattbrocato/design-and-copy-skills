**Use dividers.** For about 30 uniform, scannable rows, thin dividers (or subtle row hover states) are the best fit.

- **Cards** add borders, padding and shadows to every item. Across 30 items that's visual noise, and it wastes vertical space.
- **Space only** is cleanest, but row boundaries blur. That hurts when each row has its own action button, because users need to see which button belongs to which title.
- **Dividers** keep rows distinct at low cost. Inset them to align with the title text, and use a low-contrast color.

If you need read/unread state, use a subtle background tint or a dot instead of heavier separation. Group by day with small headers if the list grows.
