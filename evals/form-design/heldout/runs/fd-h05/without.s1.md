1. **Country:** Searchable select (combobox/autocomplete). With about 190 options, a plain dropdown is a long scroll, and typing "Ger…" gets people there fast.
2. **Delivery speed:** Radio buttons. There are only three options, and users need to compare price and timing side by side, so show them all at once.
3. **Gift note:** Multi-line textarea with a live character counter (e.g. "0/200"). A note can run long enough to need several lines, and the counter shows the limit before anyone hits it.
