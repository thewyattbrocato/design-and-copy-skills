1. **Country:** Searchable combobox (type-to-filter select), because scrolling a 190-item dropdown is slow and typing a few letters is fast.
2. **Delivery speed:** Radio buttons, because there are only three options with different prices and times, and users should see all of them at once.
3. **Gift note:** Multi-line textarea with a live character counter (for example "0/200"), because the note is free text, optional, and has a limit users should be able to see.
