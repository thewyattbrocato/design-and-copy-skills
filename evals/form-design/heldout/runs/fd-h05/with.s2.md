1. **Country:** Use a searchable select (autocomplete) with `autocomplete="country"`. With about 190 known options, people type a few letters to find theirs, and autofill can fill it.
2. **Delivery speed:** Use three visible radios, each showing its time and price (for example "Express, 2 days, $18"). There are only three options, and people need to compare price and speed side by side. Preselect Standard.
3. **Gift note:** Use a multi-line textarea labeled "Gift note (optional)" with a live counter such as "0/200". Set `maxlength` to 200 so people can't type past the limit, and show the count so they can see how much room is left.
