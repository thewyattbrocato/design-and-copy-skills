1. **Country:** Searchable select (combobox/autocomplete), because 190 options is too many to scan in a plain dropdown, and typing "Ger…" is much faster.
2. **Delivery speed:** Radio buttons (as selectable cards), because there are only three options and each has a price and timeframe, so users should see them all side by side.
3. **Gift note:** Multi-line textarea with a live character counter (e.g., "0/200") and `maxlength=200`, because it's free-form text and users need to know how much room is left.
