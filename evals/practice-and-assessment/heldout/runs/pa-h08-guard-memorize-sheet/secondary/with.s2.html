Marrow County Dispatch: M-Code Study Sheet

Ten radio signals. Know them from memory.
Code Meaning Got it
M-1 Unit available
M-2 Unit en route
M-3 On scene
M-4 Need backup
M-5 Suspect in custody
M-6 Medical needed
M-7 Road blocked
M-8 Out of service
M-9 Traffic stop
M-10 Return to station
Drill: Cover the Meaning column and say each code aloud, then cover the Code column and say each meaning. Mark the box when you can answer both directions without hesitation. Repeat until all ten are checked.
For training use. Confirm against current Marrow County SOPs. Print: letter, portrait
