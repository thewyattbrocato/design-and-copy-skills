# Pocketlane first-run walkthrough

## Screens

**Screen 1: Welcome**
- **Headline:** Hi, welcome to Pocketlane!
- **Body:** Let's get your money in one place. This takes about five minutes, and you can skip any step.
- **Buttons:** Let's go | Skip for now

**Screen 2: Link your bank**
- **Headline:** Connect your bank
- **Body:** Link an account so your transactions show up automatically. It takes one to two minutes. Pocketlane has read-only access, so it can see your transactions but can't move your money.
- **Buttons:** Link my bank | I'll do this later

**Screen 3: Set a monthly budget**
- **Headline:** Give your categories a budget
- **Body:** Pick a category like Groceries or Eating out, and set how much you want to spend in it. Budgets reset on the 1st of each month, so you start fresh every month.
- **Buttons:** Set a budget | I'll do this later

**Screen 4: Add an expense**
- **Headline:** Track cash and other spending
- **Body:** Not everything shows up from your bank. Add an expense by hand with an amount and a category. A note is optional, but it helps if you want to remember what it was for later.
- **Buttons:** Add an expense | Finish setup

**Skip message (shown when someone skips):**
- You can find this walkthrough anytime under Settings. No rush!

## Tooltips

**Link a bank account**
Takes about 1–2 minutes. We only get read-only access, so we can see your transactions but never move your money.

**Set a monthly budget**
Budgets reset on the 1st of every month, so each month starts fresh.

**Add an expense by hand**
You'll need an amount and a category. Add a note if you'd like, but it's optional.

---

I chose the four-screen order (welcome, bank, budget, expense) to follow the setup flow. The button labels and the "about five minutes" line are my guesses, so check them against the real flow before launch.
