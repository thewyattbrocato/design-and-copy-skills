The hover rule changes only the background, so the white text stays and lands on the pale color. Use a darker green on hover so the white text keeps its contrast:

```css
.save:hover { background: #185a4a; }
```

If you want the pale hover background, the text has to change too:

```css
.save:hover { background: #e8f3f0; color: #1f6f5c; }
```
