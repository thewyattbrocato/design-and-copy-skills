The hover rule changes the background to a pale mint but leaves the text white. Give the hover state a darker background so the white text stays readable:

```css
.save:hover { background: #185a4a; }
```

White on `#185a4a` is about 8:1 contrast, which clears WCAG AA. If you'd rather keep the lighter hover look, switch the text color on hover too, for example `color: #1f6f5c;`. That gives dark green on pale mint.
