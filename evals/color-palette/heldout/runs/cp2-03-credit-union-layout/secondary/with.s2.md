**Pick: deep forest green (#1F4D3A).** Navy is the default bank color, so it would make Fernhollow look like every other lender. Plum reads as decorative and is harder to keep calm on a dark footer. Forest green signals stability and a local, member-owned identity, and it's distinct from the banks.

**Palette**

| Role | Value | Use |
|---|---|---|
| Lead | `#1F4D3A` | Join button, headings, icons, focus rings, footer ground |
| Lead hover | `#163829` | Join button hover |
| Page ground | `#F5F7F4` | Page background (neutral with a trace of green) |
| Surface | `#FFFFFF` | Calculator tiles, testimonial cards |
| Tint | `#E6EEE9` | Rate strip ground |
| Text | `#1C2620` | Body text |
| Muted text | `#56655C` | Labels, captions |
| Footer text | `#E9EFEC` | Footer body text |
| Footer muted | `#A9BDB3` | Footer secondary text, hours labels |

Contrast ratios are my estimates, since I can't measure them here. Body text on the page ground is about 14:1. Join button text (white on `#1F4D3A`) is about 9.6:1. Footer text is about 12:1 and footer muted about 7:1. Rate figures in lead on the tint are about 8:1. Check them in a tool before shipping.

**Where color goes, by section**

- **Hero:** Keep the ground light (`#F5F7F4`) and let the headline use lead green. The Join today button is the only solid lead-filled element on the page. Don't add a gradient. If a photo sits behind the hero, put a scrim under the text and check the brightest spot.
- **Rate strip:** Tint ground (`#E6EEE9`). Rate figures in lead green, labels in muted gray. Don't color rates green for "up" or red for "down," because that makes a neutral figure look like a gain or loss. If you show a change, use an icon and words too.
- **Calculator tiles:** White surfaces with a neutral border. Lead color only on each tile's icon and title, plus one text link ("Calculate"). Don't give each tile its own accent; three colors would compete with the Join button.
- **Testimonials:** Neutral cards, no colored fills. Quote marks and names in lead or muted gray. Avoid colored avatar backgrounds.
- **Footer:** Dark lead ground with off-white text, muted text for hours and secondary links. Links get an underline, not a bright accent. This is the only dark area, so the contrast will carry it.

**Where color should not show up**

- Body copy, rate numbers, dividers, card borders, and placeholder text. These stay neutral.
- Any second hue. The homepage needs no accent color; if you add status colors for a notice bar, use a distinct hue and pair each with an icon and words.
- Multiple lead-filled buttons. One solid action per view.

**Notes**

- Testimonial and rate content are placeholders in this palette. Don't publish invented quotes, ratings, or rates; use real ones or leave those slots marked.
- The one trade-off: a green hero reads quiet. If the Join button feels weak against the light ground, make the button larger before you add a second color.
