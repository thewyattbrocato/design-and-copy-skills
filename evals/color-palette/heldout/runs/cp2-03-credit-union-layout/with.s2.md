**Pick: deep forest green, `#1F4D3A`.** No brand color was given, so I chose it for three reasons:
- It suits the name Fernhollow.
- It reads as growth and steadiness for a member-owned local institution.
- Navy is the default for every bank in town, so green sets the credit union apart. Plum is distinctive but says less about money and trust.

## Palette

| Role | Value | Use |
|---|---|---|
| Lead | `#1F4D3A` | Hero fill, links, icons, hover borders |
| Action accent | `#E8B84A` (brass) | The Join today button only |
| Page | `#F7F8F4` | Background, a green-leaning off-white |
| Tint band | `#E6EEE8` | Rates strip |
| Text | `#1A2420` | Body text and rate figures |
| Footer | `#14211B` | Dark green-black ground |
| Footer text / links | `#E8EEE9` / `#A9C7B5` | Hours and links on the footer |

## Where color goes

- **Hero:** Fill it solid forest with white text, about 9.6:1. The brass Join today button sits on it with forest label text, about 5.2:1. This is the one place the accent appears, so the button is the loudest thing on the page.
- **Rates strip:** Use the pale green tint band, with the rate figures in near-black text. Labels can be forest. Don't color the figures green, and don't use red/green to show rates going up or down. If a change needs showing, use an arrow and a word.
- **Calculator tiles:** Use white cards with a thin neutral border. Give each a forest icon and a forest link or arrow, and a forest border on hover. All three tiles get the same treatment. Don't give them three colors or fill them solid.
- **Testimonials:** Keep this row neutral: page background, dark text, and maybe a small forest quote mark. Color here would compete with the content, and the section depends on looking plain and honest.
- **Footer:** Use the dark green-black ground with off-white hours (about 14:1) and pale-green links. Don't use brass here, and don't use the lead green as a fill. The footer should recede.

## Where color shouldn't go

- Body text, headings and rate numbers stay near-black. Forest is for links and icons, not paragraphs.
- No gradients, and no brass beyond the one button.
- Keep error and warning states red and amber with an icon or label, so they aren't confused with the brand green.

**Notes:**
- I worked out the contrast ratios by hand and didn't run a checker, so treat them as estimates.
- The trade-off is that the forest hero and dark footer bookend the page. This is deliberate, but if the hero feels heavy, use a light hero with a forest Join button instead.
