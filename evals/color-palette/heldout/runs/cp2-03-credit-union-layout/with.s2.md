**Pick: deep forest green.** It fits the name, and green reads as money and growth. Navy is the default for every bank, so a member-owned credit union gains little by using it. Plum feels more like a boutique or wellness brand than a place that holds your savings. Green also shows the local, not-a-big-bank character without hurting trust.

**Palette (contrast ratios are my estimates, since I didn't run a checker)**

| Role | Value | Use |
|---|---|---|
| Forest, lead | `#1F4D3A` | Hero ground, primary buttons, links. White text on it is about 9:1. |
| Forest, deep | `#14332A` | Footer ground. Off-white `#E8EFEA` on it is about 11:1. |
| Forest, tint | `#E6EFE9` | Rate strip ground and tile hover. Forest text on it is about 7.5:1. |
| Neutral base | `#F7F8F6` | Page ground, a green-tinted off-white. |
| Text | `#18211D` | Body text, a green-tinted near-black. |
| Accent, brass | `#C9962B` | One small accent, used sparingly. |

**Where color goes**

- **Hero:** This is the one big block of forest, with white headline text. **Join today** is the only brass element in the hero, using `#C9962B` with `#18211D` text at about 6.5:1. That makes it the single loudest thing on the page. If you'd rather not add a second hue, make it white with forest text instead.
- **Rate strip:** Keep it quiet, on the pale tint or off-white ground. Rate numbers are large forest text, and labels are dark gray-green at 4.5:1 or better. Don't color rates up or down in red and green. If direction matters, use an arrow and a word.
- **Calculator tiles:** Use white cards on the off-white ground, with a thin neutral border. Forest shows only in each tile's icon and its "Calculate" link. Don't fill the tiles solid green. Three green blocks would compete with the hero.
- **Testimonials:** Keep them neutral: dark text on off-white, with no colored cards. A small forest quote mark or name line is enough. Real member quotes belong here, so don't put invented ones in the design. Use visible placeholders until you have them.
- **Footer:** This is the deep forest ground with off-white text. Branch hours are plain text. Links are underlined or a lighter mint `#A9CDB8`, which is about 7:1 on `#14332A`.

**Where color shouldn't appear**

- Body text, which stays near-black.
- Gradients. The hero should be flat forest or a photo with a scrim.
- Error states. Use a separate red with an icon and a label, so errors never look like the brand color.
- Brass anywhere beyond the one button and perhaps a thin rule. If it shows up in more places, it stops being an accent.

**Balance:** The page is mostly off-white. Forest appears twice as large blocks, at the top and the bottom, so the page is framed by the brand color. The middle is calm, which keeps the rates and calculators easy to read.

I assumed no existing logo or brand colors. If you have a logo, check that the forest green sits well beside it.
