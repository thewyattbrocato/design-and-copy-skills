```css
:root {
  --color-heading: #14213d;
  --color-bg-page: #fcfbf8;
  --color-bg-card: #ffffff;
  --color-text-body: #3a4660;
  --color-button-primary: #0b6e4f;
  --color-error: #c2410c;
}
```

`--color-error` covers both error text and borders, so use it for either. If you add a button label color later, something like `--color-button-primary-text` would fit the same naming pattern.
