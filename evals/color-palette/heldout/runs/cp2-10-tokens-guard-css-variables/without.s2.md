```css
:root {
  --color-heading: #14213d;
  --color-bg-page: #fcfbf8;
  --color-bg-card: #ffffff;
  --color-text-body: #3a4660;
  --color-button-primary: #0b6e4f;
  --color-error: #c2410c;
}
```

`--color-error` covers both error text and borders, so use it for either. If you later need separate values (say, a tinted error background), add something like `--color-bg-error`.
