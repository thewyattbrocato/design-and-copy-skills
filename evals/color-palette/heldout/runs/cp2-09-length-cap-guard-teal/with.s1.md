Use a teal-tinted off-white like `#f6f9f9` for page backgrounds and a deep teal-gray like `#162628` for body text, so the neutrals share the brand's hue instead of fighting it. By my hand estimates, the text on that background is about 14:1, and `#0f7c80` itself is about 4.7:1 on it, so it also works for links.
