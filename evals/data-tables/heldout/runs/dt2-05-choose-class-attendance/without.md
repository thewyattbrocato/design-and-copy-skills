I'd use a table, because owners will want to look up specific numbers and 72 values fit on a page. I'd add a headline above it and light shading inside it.

**Layout**
- **Across the top:** Jan, Feb, Mar, Apr, May, Jun, then one extra column for change (Jan to Jun, or Jun vs. the six-month average). Time reads left to right, and the change column gives the trend without anyone doing subtraction in the meeting.
- **Down the side:** 12 rows, grouped by class, with the three gyms nested under each class. Spin has Northgate, Riverside and Old Mill, then yoga has the same three, and so on. Classes are probably the unit of decision (add a boxing slot, cut a barre session), and grouping this way puts the gym-vs-gym comparison for a class next to each other. If your owners each care mainly about their own gym, flip it and group by gym.

**What else goes on the page**
1. **A one-line headline above the table.** For example: "Yoga is up at all three gyms. Barre is down at Old Mill." Whatever the data says, the page should state the main finding so nobody has to find it.
2. **Shading in the cells.** Shade each class's block on its own scale, since spin and barre likely have very different typical attendance. Don't use one scale across all 72 numbers, or the big classes will look hot everywhere and hide the shifts in the small ones.
3. **Whole numbers.** Average weekly attendance doesn't need decimals.
4. **A small totals row per class (optional).** Use it if the owners think in terms of the whole business rather than each gym.

**When to use something else**
If the main question is how things are trending rather than what the numbers are, use four small line charts, one per class. Put months on the x-axis and draw one line per gym, with the same y-axis scale on all four. That shows trends better than a table but is worse for looking up exact values. If there's room, put it above the table.

I'd avoid a list, and I'd avoid one big chart with 12 lines, which turns into spaghetti.
