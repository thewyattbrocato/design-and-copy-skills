I'd use a table, with months across the top and 12 rows down the side.

**Rows:** group by class (Spin, Yoga, Boxing, Barre) and put the three gyms under each one. Owners will mostly want to know whether Northgate's yoga is doing better than Riverside's, and this layout puts those numbers next to each other. If each owner mostly cares about their own gym, flip it and group by gym, with the four classes under each.

**Columns:** Jan, Feb, Mar, Apr, May, Jun, left to right so time reads in the usual direction. Then add two summary columns:
- **6-mo avg**, so each row has a single typical number.
- **Jan→Jun change**, as a percent or a plain difference. This is the column people will look at first.

**Optional extras:**
- A light color shade on the cells (darker means higher attendance) so patterns show up without reading every number. Shade within each class, since spin and barre have different capacities.
- A subtotal row for each gym or class, if the owners care about overall totals.
- One line above the table with the main takeaway, such as "Yoga is up at all three gyms; Old Mill boxing is down 20%." Owners will read that before they read the table, so write it after you've looked at the numbers.

**Why not the alternatives:**
- A **list** would be 72 lines and nobody could compare anything.
- A **3×4 grid of small line charts** works if the trends matter more than the exact numbers. It's harder to read exact figures from, and it's harder to talk through in a meeting. If you want a visual, put a tiny trend line in the table instead of a separate chart.

Use whole numbers, since attendance averages don't need decimals. Right-align the numbers and sort the rows consistently, with the same gym order under every class.
