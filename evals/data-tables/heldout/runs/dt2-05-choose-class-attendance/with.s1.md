I'd use one table with 12 rows and 6 month columns. A list would bury the comparisons, and 72 numbers is too many to read as prose.

**Down the side:** the 12 class-and-gym combinations. Group them by class (Spin, Yoga, Boxing, Barre), with the three gyms listed under each in the same order every time. Owners usually ask "is boxing working?" or "why is Old Mill's yoga soft?", and this grouping puts the gyms you'd compare side by side. If each owner mostly cares about their own gym, group by gym instead. The other layout is a clean flip of this one.

**Across the top:** Jan, Feb, Mar, Apr, May, Jun, left to right so the trend reads in the natural direction.

**What to add:**
- **A final column for Jan→Jun change.** Use the absolute change in attendees, with a % change if you have room. This is the column the owners will look at first. They shouldn't have to subtract in their heads.
- **A "typical" figure per class.** Either a bold subtotal row per class (all three gyms combined) or a six-month average column. Pick one so the page doesn't get crowded.
- **A title that says what the numbers are.** Something like "Average weekly attendance per class, by month, Jan–Jun 2026". Put the unit in the title or header and leave it out of the cells.

**Formatting:**
- Right-align the numbers, use the same number of decimals in every cell (whole numbers are probably enough), and use a tabular-figure font so the digits line up.
- Separate rows with light hairlines or whitespace, not a grid. Add a slightly heavier line between class groups.
- Mark the change column with a minus sign for declines, not color alone. If you highlight anything, highlight only the one or two cells you plan to talk about. Don't color every number.
- Write "—" for any missing value, never a blank or a 0.

**One optional extra:** a one-sentence takeaway above the table, such as "Boxing is up at all three gyms; barre is down at Old Mill." On a page that will be discussed, that sentence does more than any styling.

If you'd rather show the trend as a shape, 12 tiny line charts in the same 4×3 grid would also fit on one page. But owners tend to ask "what was the actual number in March?", and the table answers that directly. I'd lead with the table.
