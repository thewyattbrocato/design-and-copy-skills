**Use a table, with a short headline above it.** 72 numbers fit comfortably on one page, and owners will want to look up specific values ("what's Riverside barre doing?"). A chart makes that harder. A list would be too long.

**Layout**
- **Across the top:** January to June, six columns. Time reads left to right, so trends show up as you scan along a row.
- **Down the side:** class, with the three gyms nested under each class. That gives 4 groups of 3 rows, or 12 rows in all. Grouping by class puts the gyms next to each other for the same class, which is the comparison owners will most likely make. If the Thursday conversation is really about each location on its own, flip it and group by gym.
- **One extra column on the right:** change from January to June, as a number or percent. It answers "up or down?" without making people do subtraction across six columns.
- **Optional:** a total row for each gym (the sum of the four classes). That's total weekly attendance, so adding the averages is valid.

**What else goes on the page**
- **A one- or two-line takeaway above the table.** For example: "Spin is up everywhere; Old Mill barre has dropped 20% since January." Write it after you've looked at the numbers. Owners should get the point before they read any cells.
- **Light formatting to guide the eye.** Subtle shading on the change column (green or red), or bold on the few cells that matter. Don't shade all 72 cells. If everything is highlighted, nothing stands out.
- **Plain labels.** Say "avg weekly attendance" in the title and keep the units consistent.

**When to use a chart instead:** if you have room, four small line charts (one per class, three lines each for the gyms) show the trends more clearly than the table. A table plus a takeaway line is enough for a one-page handout. I'd only add the charts if you want the trends to be obvious at a glance, and then I'd shrink the table or put it on the back.
