A blank cell is ambiguous. Readers can't tell whether the value is unknown, not applicable, or was forgotten. Filters and formulas may also silently skip it.

A default of 0 is worse because it looks like real data. It drags down averages, totals, and minimums, and nobody can tell a measured zero from a missing value.

A dash or "n/a" shows the value was deliberately left out, so readers know it isn't an oversight. It also can't be mistaken for a number. Pick one convention for the whole team. Use "n/a" for "doesn't apply" and a dash for "unknown" if you need to tell those apart.
