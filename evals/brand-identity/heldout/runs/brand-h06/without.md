# Southbank Reading Room logo: layouts by placement

I haven't seen the artwork, so I'm treating it as two parts: the **mark** (three stacked books forming an S) and the **wordmark** (the name). Everything below is built from those two parts. Check the details against your actual files.

## Prep: build a small logo kit first

Your designer should make these master files once and reuse them everywhere:

1. **Horizontal lockup**: mark on the left, name on the right, vertically centered.
2. **Stacked lockup**: mark above, name below, centered.
3. **Mark only**: no text.
4. **Wordmark only**: optional, for tight spots.
5. **Color variants** of each: full color, one-color dark, one-color white (reversed).

**Two-line name option:** "Southbank" on line one and "Reading Room" on line two, with the lines matching in width. This makes the name compact enough for the narrow and square formats.

**Clear space:** keep a margin around every lockup equal to the height of one book in the stack. Nothing else enters that margin.

**Minimum size:** pick a floor for the mark, for example 24 px on screen or 0.4 in in print. Below that, drop the name. Test the smallest version to make sure the three books still read as an S.

## 1. Wide website header

**Use:** horizontal lockup, with the name on one line or two.

- Place it at the left edge, vertically centered in the header bar. Navigation sits to the right.
- Mark height should be about 60–70% of the header height. The name's cap height should be roughly half the mark height, so the name doesn't overpower the stack.
- Use full color on a light background. If the header is dark or photographic, use the white version.
- Make the logo link to the home page.
- **On mobile**, switch to the mark plus a smaller one-line or two-line name. If the width is under about 320 px, use the mark alone with the name as hidden text for screen readers.
- Export as SVG. Add a transparent PNG fallback.
- Give the image alt text: "Southbank Reading Room".

## 2. Square social avatar

**Use:** mark only, centered. Most platforms crop avatars to a circle, and the name would be unreadable at thumbnail size.

- Work on a square canvas, 1024×1024 px. Keep the mark inside a central circle about 70% of the canvas width, so a circular crop doesn't clip it.
- Use a solid brand-color background with the mark in white or cream. Alternatively, use a light background with the full-color mark. Choose whichever stands out better in a feed.
- Center the mark optically, not mathematically. An S made of stacked books may be heavier on one side, so nudge it until it looks centered.
- Check the result at 48 px and 32 px.
- If the name must appear, put it in the profile name field rather than in the image.

## 3. Narrow bookmark

**Use:** stacked lockup, or the mark with the name set vertically. The bookmark is tall and thin, so use the height rather than the width.

- A typical size is 2 × 6 in. The mark should be no wider than the width minus the clear space on each side.
- **Option A, stacked and centered (safest):** mark near the top third, name below in two lines, "Southbank" over "Reading Room". Leave open space below for a tagline or web address in small type.
- **Option B, rotated:** mark at the top, with the name running vertically up the spine, rotated 90°, reading bottom to top. This looks more designed, but it's harder to read. Use it only if the name stays large enough.
- Keep important elements at least 0.125 in from the trim edge, and add 0.125 in of bleed if the background is a color.
- Use one or two colors to keep printing cheap. A solid color field with the white version works well.
- Make the hole or tassel area at the top clear of the artwork.

## 4. Canvas tote bag

**Use:** stacked lockup, large and centered, in one color. Alternatively, use the horizontal lockup if the bag is wide and low.

- Screen printing works best with one flat ink color. Use the one-color version with no gradients, no thin hairlines, and no tiny text.
- Choose ink to contrast with the canvas: dark navy or black on natural canvas, white or cream on a dark bag.
- Print width is about 8–10 in on a standard tote. Place the top of the artwork roughly 3–4 in below the top seam, and center it on the bag.
- Check that the thinnest lines in the logo are at least about 1 pt (0.35 mm). Thicken them in the print version if they're thinner.
- Send the printer a vector file (SVG, PDF, or AI) with text converted to outlines.
- Optional: a smaller mark-only version on the back or on a pocket.

## Common mistakes to avoid

- Stretching or squashing the logo to fit a space.
- Placing the logo on a busy photo without a solid or darkened area behind it.
- Using the full lockup at tiny sizes.
- Redrawing the mark by hand for each use. Always start from the master files.
