**Assumptions:** the mark is flat and solid, one color plus reversed. The three-book S is the symbol, the name is set in one typeface, and no tagline is built in. Colors aren't specified, so I describe everything as one ink color on a light or dark ground. Pick the brand color separately.

## Master parts (build these first)

1. **Symbol, standard:** the three-book S. It must read in solid black on white before anything else.
2. **Symbol, small:** a heavier redraw with fewer details. Drop book-spine lines, page edges and titles. Widen the gaps between books so the S still reads at 24 px. This is a separate drawing, not the standard symbol shrunk.
3. **Wordmark:** "Southbank Reading Room". Make one custom adjustment, such as a tuned S or a book-spine-height cut on one letter. Match the stroke weight to the symbol's book edges.
4. **Stacked name:** "Southbank" on line one and "Reading Room" on line two, for narrow spaces.
5. **Clear space:** the height of one book on every side. **Minimum size:** the full lockup no smaller than 120 px wide on screen (about 30 mm in print). Below that, use the symbol alone.

## 1. Wide website header: horizontal lockup

- Symbol on the left, name on the right, vertically centered on the symbol.
- Name on one line, or two lines (Southbank / Reading Room) if the header is under about 80 px tall. Two lines usually look better beside a square-ish symbol.
- Symbol height about 40–56 px on desktop. Name cap height about 40% of the symbol height.
- Gap between symbol and name: about the width of one book spine.
- Left-align to the page grid. Nav goes on the right. Leave the center empty.
- Light header: ink color on white. Dark header: use the reversed (white) version. Don't place it on a photo without a solid band behind it.
- On mobile, keep the symbol and drop to the stacked name, or show the symbol only with the name as page text.

## 2. Square social avatar: symbol only

- Use the symbol alone, with no name. Platforms crop avatars to circles and show them at 32–48 px, so the name would be unreadable.
- Use the small, heavy symbol. Center it optically and fill about 60% of the width. This keeps it inside a circular crop with margin to spare.
- Put it on a solid brand-color field with the symbol reversed, or on white in ink. Reversed on color is easier to spot in a feed.
- Test it at 32 px and inside a circle crop. If the bottom book touches the edge, shrink the symbol.
- The name goes in the profile's name field, so it needs no place in the image.

## 3. Narrow bookmark: stacked vertical

- Typical size is about 50 × 150 mm. Use a single column, centered.
- **Top:** the symbol, about 70% of the bookmark width.
- **Below:** the stacked name, one word per line if needed (Southbank / Reading / Room), centered, tight leading.
- **Option:** run the full name rotated 90° up the spine edge, reading bottom to top, as on a book spine. This echoes the mark. Use it only if the name still reads clearly. Check that it doesn't make an awkward word break.
- Leave a generous plain area below for a hole and tassel, or for a URL or hours in small text. Keep any tagline separate from the logo.
- Print in one ink on a light stock, or reversed on a dark stock. Avoid fine lines because paper stock varies.

## 4. Canvas tote bag: bold, one-color screenprint

- Use a single flat ink on natural canvas, or white ink on a dark tote. Screenprinting doesn't hold hairlines or gradients, so use the heavy small symbol cut for print.
- Layout: a large symbol centered on the bag face, about 20–25 cm wide, with the stacked name set underneath at about a third of the symbol's width. This is the most readable arrangement from a distance.
- **Alternative:** the horizontal lockup across the upper third, about 25 cm wide, for a quieter, more editorial bag.
- Place the artwork about 8–10 cm below the top seam and keep it centered between the handles. Avoid seams and handle stitching.
- Make sure no counters (the gaps between the books) are narrower than about 2 mm at print size, or the ink will fill them in.
- Ask the printer for a proof on the actual fabric.
