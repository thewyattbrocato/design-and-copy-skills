Assumptions: the mark (three stacked books forming an S) already exists and works, so this is about adapting it, not redrawing it. Nothing is locked inside the mark except the name, which stays a separate element. Use one flat color from your existing palette, plus a reversed version for dark grounds.

## Files to build first
- **Symbol only:** the S-stack on its own.
- **Horizontal lockup:** symbol on the left, name on the right.
- **Stacked lockup:** symbol above the name, centered.
- **Small-size symbol:** a slightly heavier redraw. Thicken the gaps between books and drop any spine detail, such as titles, bands or lines, that vanishes at small size.
- **Colors:** one solid color on light, one reversed (white or cream) on dark, and solid black for stamps and print.
- **Clear space:** the height of one book on every side. Pick a minimum size for each lockup and write it down. Roughly 24 px tall for the symbol on screen is a sensible starting point.

## 1. Wide website header
- Use the horizontal lockup, left-aligned, on a light or white bar.
- Set the symbol at about 40–48 px tall on desktop.
- Set the name beside it on one line: "Southbank" and "Reading Room" on the same line, or on two lines if the bar is tall enough. One line is easier to read.
- Align the name's cap height or its two-line block to the symbol's height. The gap between symbol and name is about half a book width.
- Navigation goes to the right. Don't put a tagline in the header.
- On mobile, keep the symbol and shorten the name, or drop to the symbol alone at 32 px with the name as page text. Don't shrink the full lockup until the name is unreadable.
- If the header sits over a photo or a dark band, use the reversed version.

## 2. Square social avatar
- Use the symbol only, with no name.
- Platforms crop avatars to a circle, so keep the symbol inside the central ~70% of the square. Test it in both square and circle crops.
- Center it optically. The S-stack is probably heavier on one side, so nudge it by eye.
- Use the small-size redraw. The avatar will often appear at 32–48 px in feeds and comments.
- Put it on a solid brand-color field with the symbol reversed, or on white with the colored symbol. Pick whichever stands out more against the platform's background. Reversed on a solid color usually does.
- The name appears next to the avatar on every platform, so it doesn't need to be in the image.

## 3. Narrow bookmark
- A bookmark is tall and thin, around 2 × 6 in (5 × 15 cm), and the mark can use that.
- **Option A, stacked lockup:** symbol near the top, the name centered below it. The name must fit the narrow width. Break it into three short lines ("Southbank / Reading / Room") and keep the type size large enough to read.
- **Option B, rotated name:** the symbol sits at the top and the name runs vertically up the spine, reading bottom to top like a book spine. This matches the books idea, but keep it to one line and test that it stays readable.
- Pick one. Option A is safer for legibility, and Option B is more distinctive.
- Leave the bottom third for a tassel hole or a blank area, so it doesn't feel crowded.
- Print one or two flat colors. Avoid fine detail, since paper stock and trimming blur it.
- A website address or "Open to all" can go at the foot as a separate small line, never joined to the mark.

## 4. Canvas tote bag
- Screen printing on canvas needs flat shapes, few colors and no hairlines. This is the main reason to build the one-color versions.
- Use the stacked lockup, centered, in a single ink color. Navy, black or a deep brand color on natural canvas works. Use white or cream ink on a dark bag.
- Size: the symbol about 6–8 in wide, with the name below it in a clean, readable size. Position it in the upper-middle of the bag's face, not the center, so it sits above where the bag bulges when carried.
- Don't use gradients, shadows or tints. If the mark has any, flatten it for this use.
- Ask the printer for a vector file and confirm the minimum line thickness they can print, which is usually about 1 pt.
- Optional: a large, cropped, tone-on-tone S-stack on the bag's face with the small lockup beneath it. This is a decorative extra, so keep the standard lockup as the main version.

## Checks before you finalize
- Print or view each version solid black on white, then reversed. If the S stops reading as an S, strengthen the gaps between books.
- Test the symbol at 16–32 px for the favicon and avatar.
- Read the name aloud in each layout (one line, three lines, rotated) to confirm it still reads as "Southbank Reading Room."

One trade-off: the rotated bookmark is more memorable but harder to read. If the library will hand these out to people who don't already know the name, choose Option A.
