Assumptions: the mark is a flat, solid stack of three books that forms an S, and the name is "Southbank Reading Room". The mark should work in one color and reversed. I haven't seen the artwork, so check the specifics below against the real file.

## Core set

Build these first and derive every application from them:

- **Symbol:** the S-stack alone.
- **Horizontal lockup:** symbol on the left, name on the right. The name is on two lines, "Southbank" over "Reading Room", set to the height of the symbol. Align the cap height of the first line to the top book and the baseline of the second line to the bottom book.
- **Stacked lockup:** symbol centered above the name.
- **Small-size symbol:** a heavier redraw with thicker gaps between the books, used below about 32 px.
- **Colors:** one full-color version, one solid black, and one white reversed. Every application below should work in a single color.

Clear space around any lockup is the height of one book spine. Minimum size is 24 px for the symbol alone and 120 px wide for a lockup. Below those sizes, switch to the heavier symbol or drop the name.

## 1. Wide website header

- Use the **horizontal lockup**, left-aligned, in the full-color version on a light ground.
- Keep the symbol about 40–48 px tall on desktop. At that size the two-line name stays readable.
- On mobile, keep the lockup if it fits at 32 px or taller. If it doesn't, use the symbol with "Southbank" in a single line. Don't scale the lockup down until the second line becomes tiny.
- If the header sits over a photo or a dark band, use the white reversed version. Don't put the full-color version on a busy image.
- Don't add a tagline inside the lockup. If you want one, set it as a separate line elsewhere in the header.

## 2. Square social avatar

- Use the **symbol only**, with no name. Avatars are cropped to a circle and shown at 40–48 px, where the name would be unreadable.
- Center the S-stack in a solid brand-color square. Make the symbol about 60% of the width. This leaves enough margin that a circular crop won't clip the corners of the books.
- Use the **reversed (white) symbol** on the brand color, or the full-color symbol on a plain light ground. Choose whichever has stronger contrast.
- Test it at 32 px. If the gaps between the books close up, use the heavier small-size symbol.
- The account name appears next to the avatar on every platform, so the name doesn't need to be in the image.

## 3. Narrow bookmark

The bookmark is tall and thin, roughly 2 × 6 inches, and is read held vertically. It suits a stacked layout.

- Use the **symbol on its own**, centered near the top, at about 70–80% of the bookmark's width.
- Put the name below it **horizontally, in a stacked arrangement**: "Southbank" / "Reading" / "Room", centered, each word on its own line. Check that each word fits the width. If "Southbank" is too wide, reduce the type for all three lines so they stay the same size.
- Don't rotate the name to run up the spine. It is harder to read, and a bookmark held in a book gets turned around.
- Use one or two colors, such as the brand color on a cream stock. This is the cheapest way to print it, and it is the single-color test.
- Leave the lower two-thirds open for a short line, a URL, or a hole and tassel at the top. A plain end keeps it from looking cluttered.

## 4. Canvas tote bag

Screen printing on canvas favors bold shapes and few colors.

- Use the **stacked lockup** printed at about 8–10 inches wide, centered on the upper-middle of the bag, or the symbol alone at a larger size (10–12 inches) for a bolder look.
- **One ink color only**, such as the brand color on natural canvas, or white on a dark canvas. Use the solid-black or white reversed version, with no gradients or tints.
- Check that the gaps between the books are wide enough to print. Screen-print ink spreads into fine gaps, so use the heavier small-size symbol if the gaps are narrow, even at this large size.
- Put the name beneath the symbol, or leave it off and rely on the symbol if the bag is mostly for display. Keep the URL off the front. If you want one, put it small on the back or inside.
- Keep the print at least 3 inches from the bag's seams and handles.

## Checks before you finalize

- Print the symbol in solid black at 16 px and at 1 inch. The three books and the S should both be clear.
- Say the name aloud and look at it in each crop (stacked, single line, avatar). Nothing should read as another word.
- Put the symbol and the name next to each other and confirm they share the same weight. If the name looks thinner than the books, increase its weight.
