## Shared rules

- **Clear space:** keep at least 1x of empty space around the full lockup on every side. Nothing else goes inside it.
- **Mark-to-name gap:** about 1x. Set the name's cap height to roughly 40–50% of the mark's total height. Don't let the name get bigger than the mark.
- **Minimum sizes:** don't show the lockup with the name below about 24 px tall (screen) or 25 mm wide (print). Below that, use the mark alone.
- **Color versions:** provide a full-color version for light backgrounds, a reversed version (all white or light) for dark backgrounds, and a one-color version (single ink, no tints) for fabric and screen printing.
- **Files:** deliver SVG as the master, with PNG exports at 1x and 2x for web and social.

## 4. Canvas tote bag

- **Arrangement:** stacked lockup, like the bookmark, but with the mark larger and the name below it in a single line if the bag is wide enough. If the printable area is narrow, use the mark alone.
