Here's how I'd arrange the mark in each place. The mark is the three-book S, and the name sits beside it. I haven't seen the artwork, so the proportions below are starting points for your designer to adjust. The main rule across all four is that the name drops out or moves when the space gets small, and the book-S always stays legible.

**Shared rules to build first**
- **Master files:** a horizontal lockup (mark left, name right), a stacked lockup (mark above name), and the mark alone. Use vector (SVG for web, PDF/EPS for print).
- **Clear space:** keep a margin around the mark equal to the height of one book in the stack on every side.
- **Minimum size:** the mark alone should not go below about 24 px or 0.25 in. Below that, the gaps between the books fill in and it reads as a blob.
- **Color versions:** full color, one-color dark, and one-color light (reversed out). Test each on the backgrounds you'll actually use.

**1. Wide website header**
- Use the **horizontal lockup**: mark on the left, name to its right, set on one baseline or vertically centered on the mark.
- Mark height about 60–70% of the header height, so the name's cap height is roughly the height of the top book.
- Put it on the left edge with a clear-space margin. Keep it in one color that contrasts with the header background.
- On mobile, switch to the mark alone so the name doesn't wrap or shrink too far.

**2. Square social avatar**
- Use the **mark alone**, centered, with about 15–20% padding on each side so it survives circular cropping. Platforms often crop to a circle, so keep the stack's corners inside the circle.
- Don't include the name. At avatar size the lettering is unreadable, and the S does the identifying work.
- Use a solid background (one brand color or white). Avoid transparency, because some platforms show a dark or light fill that can clash.
- Export at 400×400 px minimum, or 1024×1024 px for a crisp version.

**3. Narrow bookmark**
- Use the **stacked lockup**: mark on top, name below, centered. The bookmark's width is the constraint, so the name needs to be short enough to fit in one or two lines.
- If the name is too wide for the bookmark, set it on two lines (for example, "Southbank" over "Reading Room") and keep the lines the same width as the mark.
- Mark width about 50–60% of the bookmark width, so there's room around it.
- Print in one color on the bookmark stock. If the stock is dark, use the reversed version.
- Leave a margin at the top or bottom for a tassel or hole if the bookmark has one.

**4. Canvas tote bag**
- Use the **stacked lockup** at a large size, centered on the front, with the mark dominant and the name set below it. Make the mark the largest element, roughly 60–70% of the print width.
- Print in **one color** if you're screen printing. Each added color adds a screen and cost, and it makes the register (alignment) harder.
- Keep the thinnest gaps between books at least as wide as a fine line your printer can hold. Ask the printer for their minimum gap. Thin lines can disappear in the weave of canvas.
- Print on a dark or light canvas depending on contrast. Use the one-color version that matches the canvas, not a full-color version that may have colors clash with the fabric.
- Optional: a smaller mark-only version on the back or side.

**Handoff notes for the volunteer designer**
- Ask the printer for their file spec (vector, single color, required minimum sizes) before finalizing the tote.
- Test the avatar at its real display size on each platform.
- If you can share the original mark file or describe the current proportions (the ratio of the mark's height to the name's cap height), I can give more exact numbers.
