Here's a set of arrangements that keep the mark's three-book S readable at each size. I haven't seen the artwork, so the proportions below are relative to the mark's own unit: **x** = the height of one book in the stack. Your designer can scale from that.

## Shared rules

- **Master files:** Keep the full-color lockup (mark + name) and the mark alone as vector SVG/PDF. Also make a one-color version (all black, or the brand's single ink) and a reversed version (white or cream on dark).
- **Clear space:** Keep at least **1x** free on all sides of the lockup. Nothing else goes in that space.
- **Name text:** Use a single weight of a sturdy sans or a readable serif, set in one line or stacked as described below. Don't outline the name at small sizes, since thin outlines fill in.
- **Small-size check:** Test the mark at 16 px. If the S stops reading as an S, use a simpler fallback such as a solid silhouette, and don't shrink the detail.

## 1. Wide website header

**Layout:** Horizontal lockup. Mark on the left, name on the right, on one baseline.

- Mark height: about **1.2x** the cap height of the name, so the books and the letters feel balanced.
- Gap between mark and name: **0.5x**.
- Name: one line, sentence case ("Southbank Reading Room"), with optional smaller "Neighborhood library" tagline underneath if there's room.
- Display height in the header: 40–56 px. Export a 2x or 3x PNG as a fallback, and serve SVG where possible.
- On mobile, drop to the mark alone (see section 2) so the header doesn't wrap.

## 2. Square social avatar

**Layout:** Mark only, centered, no name.

- Export at **400 × 400 px** (or larger). Most platforms crop to a circle, so keep the mark inside a circle about **70–75%** of the canvas width, so no book edge gets clipped.
- Background: a solid field in the brand's main color, with the mark in the reversed color. A flat fill reads better at 40 px than a gradient.
- Don't include the name. At avatar size it's illegible, and the S mark carries the identity on its own.
- Check it at 40 px and at full size both inside a circle crop.

## 3. Narrow bookmark

**Layout:** Stacked lockup, vertical. Mark on top, name below, centered on the bookmark's long axis.

- Work at the printed size (for example, 2 in × 6.5 in), at 300 dpi.
- Mark width: about **60%** of the bookmark's width, centered. Keep the mark at most **1.5 in** tall so it doesn't dominate.
- Name: set in two short lines, "Southbank" / "Reading Room," centered beneath the mark. Keep each line under 80% of the bookmark's width.
- Margins: keep all artwork at least **0.25 in** from the trim edge. Keep it clear of any tassel hole or laminate edge.
- Use one color if the bookmark is printed on a light cardstock. Avoid thin hairlines; the minimum stroke should be about **1 pt**.

## 4. Canvas tote bag

**Layout:** Large, bold, one-color mark, with the name either to one side (horizontal) or below (stacked). Pick one, and use the mark alone if the design needs more space.

- Print area: a typical tote gives roughly 10–12 in wide. Make the horizontal lockup about **8–9 in** wide, or the stacked lockup about **6–7 in** tall with the mark about **4 in** high.
- Use a **one-color** version for screen printing. Every element should be one solid ink with no gradients or halftones, since canvas absorbs ink unevenly.
- Stroke minimum: about **1.5 pt** at the printed size. Fill in any gaps between books wider than about 1/16 in, or they'll close up in the print.
- Dark canvas (natural cream is fine too): use the reversed version, or print in a contrasting ink. Test one color at a time to avoid registration errors.
- Keep the mark within about **2 in** of the top seam and bottom hem on the tote, so it isn't cut off by the handle stitching.

## Handoff notes for the volunteer designer

- Give them: the mark SVG, the name typeface name and weight, the one-color and reversed versions, and this document.
- Ask them to deliver: SVG masters, a PNG for each placement at the sizes listed, and a print PDF for the bookmark and tote at true size.
- Have someone at the library check the tote and bookmark proofs at actual size before a large print run.
