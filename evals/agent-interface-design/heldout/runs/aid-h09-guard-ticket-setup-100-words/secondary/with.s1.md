Before the agent touches live tickets, ask the team lead:

1. Which ticket types count as "simple"? Propose a list from past tickets for them to correct.
2. What may it send customers without review? Set a daily cap.
3. What must it never touch: refunds, legal, cancellations, VIP accounts?
4. Who gets anything it's unsure about, and how fast?
5. Start with drafts for approval, then widen once results look clean?

Sent replies can't be recalled, so start with approval. A daily digest lists everything it did.
