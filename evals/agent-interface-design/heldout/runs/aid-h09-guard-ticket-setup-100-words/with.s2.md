**Ask first: "What should it never answer on its own, and how many auto-replies a day is OK?"**

This gate matters most because the agent sends replies to customers. Before it goes live, have the lead name the off-limits topics (billing disputes, cancellations, legal, angry customers) and set a daily cap. Start it on draft-for-approval, and promote it to auto-send once the lead has seen clean drafts.

Everything else can wait until after the first run. Assignment rules and categories can start from a proposed draft that the lead corrects.
