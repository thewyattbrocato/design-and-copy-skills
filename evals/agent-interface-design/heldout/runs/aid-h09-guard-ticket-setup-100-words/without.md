**Ask first: "What should the agent never handle on its own?"**

Before anything else, get the team lead to define the off-limits zone: billing disputes, legal threats, security incidents, VIP accounts, angry or churn-risk customers. Those always go to a human.

Everything else follows from that boundary: which tickets count as "simple" enough to auto-reply, how to route the rest, and when to escalate.

Second question: "Who owns each category, and what's their capacity?"
