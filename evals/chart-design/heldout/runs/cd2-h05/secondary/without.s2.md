She's half right. The axis doesn't need to start at zero, but the chart still needs a clear label.

**Why zero isn't required for a line chart:** Bar charts encode values as lengths, so a truncated baseline makes differences look larger than they are. Line charts encode values as positions, and a line's slope shows change without needing a zero reference. Water temperature is also a quantity where the relevant question is how much it varies, and a 20–26 °C range is a sensible window for values between 21.4 and 24.9.

**Where she has a point:** A truncated axis still makes a 3.5 °C swing look dramatic on the page. If the audience might read the slopes as large physical changes, that's a legitimate concern. Some fixes that don't require starting at zero:

- **Label the axis clearly** with units (°C) and make the tick values visible, so no one has to guess where the baseline is.
- **Tighten the range** to something like 21–25 so the data fills the plot without wasted space. This is a judgment call, but it's fine as long as the endpoints aren't clipped.
- **Add a reference line** at a meaningful threshold if one exists, such as a swimming advisory level or a seasonal average, so readers have context.

**Redoing it from zero** would make the July variation nearly invisible, which hides the thing the chart is meant to show. I'd keep the line chart, make sure the axis is labeled, and optionally tighten the range. If your coworker's concern is that readers will overinterpret the slopes, a short note in the caption ("axis starts at 20 °C") addresses that directly.
