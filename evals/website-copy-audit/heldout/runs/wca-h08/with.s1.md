- **Claims:** I dropped "the best teeth whitening available" from the whitening description because it's an unverifiable superlative. "Professional teeth whitening" is safer.
- **Phone number:** The descriptions say "Call us" but don't include a number, since I don't have one. Search results don't show a number from the description anyway.
- **Home title:** The old title was about 130 characters, so Google was truncating it. The new one puts the practice name and "Tulsa Family Dentist" first, so the location and service show in full.
- **Count check:** Your SEO person may want to paste these into a character counter to confirm. Google actually truncates titles by pixel width, not character count. Wide letters like "W" and "M" take more room, so these have a few characters of margin.
