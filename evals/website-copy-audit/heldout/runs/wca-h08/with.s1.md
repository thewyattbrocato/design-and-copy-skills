- **Home:** The old title was about 130 characters, which is why Google cut it off. The home page had no description, so I wrote one.
- **Whitening:** I dropped "the best teeth whitening available" because it's an unprovable claim. If you have a real selling point, such as a specific method or same-day results, add it. There's room for about 20 more characters.
- **Emergency:** I only say you can book same-day appointments on weekdays, since that's all you told me. If people can call on weekends, add that.
- **Location:** I wrote "Tulsa" without a state, since Google already localizes results. If your SEO guy wants "Tulsa, OK", every title still fits.

Google sometimes rewrites snippets anyway. Pixel width matters as well as character count, so check the final versions in a SERP preview tool.
