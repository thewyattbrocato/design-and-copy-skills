**Use one family that covers both scripts, and set the Hindi larger than the English.**

**Typeface**
- Pick a sans with matched Devanagari and Latin, such as Noto Sans and Noto Sans Devanagari, or Mukta, which is built for both scripts. Both are open licensed, but confirm that with the foundry.
- Don't pair a Latin face you like with whatever Devanagari fills the gaps. A mismatched fallback is the usual failure.
- Use a sturdy sans with real regular, medium and bold weights. Skip thin weights and condensed or decorative faces, because Devanagari headlines and matras break up at small sizes.
- Don't fake bold or italic. Devanagari has no true italic, so use weight and size for emphasis.
- For the PDF, embed and subset the fonts so phones don't substitute anything. Don't outline the text, because then people can't search or copy stops and times.

**What gets bigger**
Make what a rider scans for the largest, not just the title:
1. Route numbers are the biggest element, in bold, ideally in a solid badge.
2. New times are next. Use tabular figures and align them in columns, using the same 24-hour or am/pm format throughout.
3. Stop names come after that, in medium weight.
4. The title and the "what changed" line follow. Body notes and contact details are smallest.

Start with these sizes at A3 and adjust after a test print:

| Element | Size |
|---|---|
| Route numbers | 150–250 pt |
| Title | 70–90 pt |
| Times and stop names | 32–44 pt |
| Notes | 24 pt minimum |

The A3 notice will be read from a metre or two away, so nothing should drop below about 20 pt. For the phone PDF, check it at 100% on a narrow screen. Anything you'd have to pinch to read is too small. If the A3 layout shrinks badly on a phone, make a separate single-column version.

**Two scripts**
- **Size:** Devanagari looks smaller than Latin at the same point size. Match them by eye, which usually means Hindi about 10–15% larger. Don't set them equal in points.
- **Leading:** Devanagari has tall marks above and below the line, so give it about 1.5–1.6 line height. Latin can take about 1.3.
- **Layout:** Hindi first, English second, in the same weight and the same visual size. Use two parallel blocks or columns. Don't mix both languages in one line, and don't make one language a small caption under the other.
- **Shared items:** Route numbers, times and stop names in both scripts should sit on the same rows, so people can compare them.
- **Digits:** Use Western (Latin) digits throughout, since Indian riders and bus signage mostly use them. Don't mix digit systems.
- **Hindi stop names:** Have a Hindi speaker check them. Use the names riders actually say, not transliterations.

**Checks before sending**
- Print one A3 test and read it from 2 metres.
- Open the PDF on a real phone.
- Check that conjuncts render correctly everywhere, such as क्ष, त्र and श्र.
