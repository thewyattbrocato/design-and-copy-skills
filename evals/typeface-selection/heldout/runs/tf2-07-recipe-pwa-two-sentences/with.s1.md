Use a system stack, since an offline PWA can't count on a web font loading: `font-family: ui-serif, Georgia, Cambria, "Times New Roman", serif;` for recipe text, with `font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;` for buttons, labels and other UI. I haven't checked how these render on each platform. If you later want a custom face, self-host and precache the font files in your service worker so it still works offline.
