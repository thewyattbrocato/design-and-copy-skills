**What a variable font is:** A normal font comes as separate files for each style: one for regular, one for bold, one for italic, one for light, and so on. A variable font packs all of those styles into one file and adds dials (called axes) that let you slide smoothly between them. Typical dials are weight (thin to black), width (condensed to extended), and slant.

**Is it better?** It depends on what you need.

- **Better when** you use several weights or styles. One file can replace many, and it can load faster overall. It also lets the site fine-tune text sizes and weights smoothly.
- **Not necessarily better when** you only use one or two styles. A single regular file and a single bold file may be smaller than one variable file.

For your bakery site, either kind works. The variable file just gives your designer more flexibility.

**Can you legally use it on your website?** I can't tell from the file alone, so check these:

1. **Look for a license.** Your designer may have sent a license document, or the font's folder or email may mention one. Look for words like "web license," "webfont," "EULA," or "OFL" (SIL Open Font License, which is free for web use).
2. **Know that desktop and web licenses differ.** Many commercial fonts are sold for installing on your computer for design work. Putting a font on a public website is a separate right, and many licenses charge for it, sometimes based on page views or number of sites.
3. **Ask your designer.** Send a short message like: "Does the license for Marlowe-Variable.ttf cover embedding on a public commercial website? Can you send me the license terms?" If your designer made the font, check your contract too.
4. **Don't pass it along.** Even with a web license, don't give the file to anyone else or upload it to free font-sharing sites.

If the license is unclear or doesn't cover the web, ask your designer for a web-licensed version. Alternatively, use a free equivalent from a service like Google Fonts, which makes web use simple.
