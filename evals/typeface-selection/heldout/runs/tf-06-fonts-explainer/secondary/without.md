**What a variable font is:** Normally, each style of a font is its own file. Regular, Bold, Italic, and Semibold each need a separate file. A variable font packs a whole range of styles into one file, and the site can pick any point in that range. For example, it can use weight 430 (between Regular and Medium) or a slightly narrower width, without loading another file. Designers often call these adjustable settings "axes."

**Is it better?** Not automatically. It's better when you want flexibility, such as several weights across the site or fine-tuned sizes on different screen widths. It can also replace several font files with one. But if you only use Regular and Bold, a normal set of files can be just as good and a bit simpler. Modern browsers all support variable fonts, so compatibility isn't a concern. Your designer probably chose this one for flexibility, which is a reasonable choice.

**Can you put it on your website?** I can't tell from the file alone. Fonts are licensed, not sold outright, and the license controls where and how you can use them. A few things to check:

- **Look for a license file.** The download may include a README, a LICENSE or OFL.txt file, or terms in a document. If the font is under the Open Font License (OFL), web use is generally allowed, including for businesses.
- **Check whether the license covers web use.** Many commercial fonts sell desktop licenses (for design work and print) separately from web licenses. Using a desktop-only font on a website can break the license even if you own the file.
- **Check for limits.** Some web licenses cap usage by page views, number of domains, or number of sites. A bakery's site will usually fall under the basic tiers, but confirm.
- **Confirm the designer has the rights.** If the designer made the font, they can license it to you. If they bought it or downloaded it from a font site, the license belongs to that purchase and may not cover your use.

**What to ask your designer:** "Is Marlowe licensed for commercial website use? Can you send me the license terms, or the purchase receipt if you bought it?" If they made it themselves, a short written note saying you can use it on your site is enough for most cases.
