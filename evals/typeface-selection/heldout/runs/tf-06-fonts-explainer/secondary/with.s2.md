**What a variable font is:** A normal font comes as separate files for each style: Regular, Bold, Light, Italic, and so on. A variable font packs all of those styles into one file with adjustable settings, like a slider for weight (thin to heavy) or width. Your site can then pick any point along a slider instead of loading a separate file for each style.

**Is it better?** Not automatically. It's more flexible, and it can be smaller than several separate files if you use many styles. If your site only needs Regular and Bold, a normal set of files works just as well. All modern browsers support variable fonts, so either way is fine for your site.

**Can you use it on your website?** I can't tell from the file type. Whether you're allowed depends on the license, which is the terms the font's creator set for its use. Check these:

- **Who made it?** If the designer drew it themselves for your project, the terms should be in your agreement with them. Ask them to confirm in writing that you can use it on a public website.
- **Did they license it from a font company (a "foundry")?** Many licenses cover only desktop use, like designing a flyer. Using a font on a website usually needs a separate "web" license, and some are priced by how many people visit the site.
- **Is it free and open-source?** Look for the "SIL Open Font License" (OFL). That allows website use.

**How to check it yourself on a Mac:** Double-click the Marlowe-Variable.ttf file. It opens in Font Book. Press Command-I (or choose File > Show Font Info) and look for the copyright and license fields.

**What to do next:** Before you put it on the site, ask your designer:

1. "Is Marlowe licensed for use on a public website? Which license, and does it cover my domain?"
2. "Can you send web-ready versions (usually `.woff2` files) along with the license terms?"

Until they confirm, don't upload the file to the site. If the answer is unclear, the designer or the font company can usually clarify it quickly.
