**What a variable font is**

A normal font comes as separate files for each style: one for Regular, one for Bold, one for Italic, one for Semibold, and so on. A variable font packs all of those styles into one file, with a dial for each axis (weight, width, sometimes slant or x-height). Your site can then pick any point along a dial, like weight 430, without loading a separate file for it.

**Is it better?**

It depends on how you use it.

- **Better if** you want several in-between weights or a range of sizes, or you want to tweak the look (for example, make headings slightly bolder on mobile). One file can be smaller than several static files, and it's more flexible.
- **Not necessarily better if** you only need Regular and Bold. A normal set of two or three files works just as well, and the difference in page speed is small either way.

Either kind looks identical to a visitor when used the same way. The choice is about flexibility, not quality.

**Are you allowed to use it on your website?**

I can't tell from the file alone. Fonts are licensed, not sold. Using a font on a website is a different permission from using it in a document or on your computer, and many licenses cover only one or the other. Check these:

1. **Ask your designer for the license.** Designers usually get fonts from a foundry (a company that sells fonts) or a free license like the SIL Open Font License (OFL). Ask which one this is. If the designer made the font, the terms should be in your contract.
2. **Look for a license file.** Your designer may have sent a text file, a PDF, or a webpage link alongside the .ttf. The license usually says whether web use (called "webfont" or "self-hosting") is allowed.
3. **Look for these terms:** "web use," "webfont," "@font-face," "embedding," or "page views." Some paid licenses limit how many people can see the font per month. Others charge per website.
4. **Free fonts:** Open-source fonts (OFL) are generally fine to use on websites, including commercial ones like a bakery's.

If the license is unclear, send your designer a short message: *"Can you confirm this font is licensed for use on a public commercial website, and send me the license terms?"* This is a normal question they should be able to answer quickly.
