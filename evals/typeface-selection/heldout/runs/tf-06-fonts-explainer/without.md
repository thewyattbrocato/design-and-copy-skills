**What a variable font is**

A normal font family is a stack of separate files: Regular, Bold, Light, Italic, and so on. A variable font packs all of those into one file, with sliders for things like weight (thin to heavy). You can pick any point along the slider, not just the preset styles. So you could use a weight halfway between Regular and Bold if the design calls for it.

**Is it better?**

Usually, yes, for a website:
- **Fewer files and often a smaller total download.** One file replaces several, which helps page speed.
- **More design flexibility.** Your designer can fine-tune weights and sizes.
- **Wide browser support.** All modern browsers handle it.

The exception is a site that uses only one or two styles, like Regular and Bold. Then a variable file can be bigger than the two separate files you need. It isn't worse in any way that visitors would notice. For a bakery site it's a fine choice either way.

One technical note: for the web, your developer will usually convert the `.ttf` to a `.woff2` file, which is smaller. Some licenses restrict that conversion, so check this too.

**Are you allowed to put it on your website?**

I can't tell from the file name. Having the file doesn't automatically give you the right to use it online. Font licenses are often split into desktop use (print, logos, documents) and web use, and the web license is sometimes sold separately. Ask your designer:

1. **Where did Marlowe come from?** If it's a free open-source font (for example, from Google Fonts, under the SIL Open Font License), you can almost certainly use it on your site.
2. **If it's from a paid foundry,** does the license cover web use, and for what traffic level? Some are priced by monthly pageviews.
3. **If your designer made it custom,** get in writing that you have the rights to use it on the website.

Font files usually have license and copyright details built into them. If you tell me where the file is saved, I can read that information and tell you what it says. That would give you a good starting point, but the designer's confirmation or the license document is what counts.
