**What a variable font is**

A normal font family is a separate file for each style: Regular, Bold, Light, Italic, and so on. A variable font packs a whole range of styles into one file. Instead of a few fixed weights, you get a slider. Weight can be 400, 450 or 700, anything in between. Some variable fonts also have sliders for width or slant.

**Is it better?**

It's different, and for a website it's usually a bit better:
- **Fewer files.** One file replaces four to six, so the site can load a little faster.
- **More control.** Your designer can fine-tune the heading weight instead of choosing between "regular" and "bold".
- **Same look.** Visitors won't see a difference in quality. It's a convenience for whoever builds the site.

It isn't automatically better. If you only use two or three styles, the file-size savings are small. Nearly all current browsers support variable fonts, so compatibility isn't a worry.

**Can you put it on your website?**

I can't tell from here. Having the file doesn't mean you have the right to use it online. Font licenses are separate from the file itself, and many cover desktop use (print, logos, documents) but not websites. Ask your designer these questions:

1. Is Marlowe licensed for **web use** (self-hosting or embedding on a website)?
2. Is the license in **your bakery's name**, or only the designer's? Some licenses can't be passed on to a client.
3. Is there a limit on **monthly page views** or number of domains?
4. Is it an open-license font, such as the SIL Open Font License? If so, web use is generally fine, but they should confirm it.

Ask for the license document in writing and keep it with your site records. I'm not assuming anything about Marlowe's terms. That would only be a clue, and the foundry or your designer's answer is what counts.

**Two practical notes**

- A `.ttf` file works, but your developer will normally convert it to the smaller `.woff2` web format. Many licenses require that conversion to be allowed, which is another thing to confirm.
- Ask your developer to set a normal fallback font, so the text still looks fine if Marlowe is slow to load.
