Set the names in Cormorant Garamond SemiBold, a classical serif that reads romantic without being ornate, with the stack `"Cormorant Garamond", "EB Garamond", Garamond, Georgia, serif` so it degrades cleanly if the web font fails to load. Keep the schedule and RSVP form in a plain sans like Inter, and use the serif only for the names, large and in mixed case, since it gets thin at small sizes.
