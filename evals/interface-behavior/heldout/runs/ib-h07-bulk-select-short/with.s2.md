Assumed: desktop users, frequent sessions.

- **Checkboxes:** Show a checkbox on every row. Shift-click selects a range, and the header checkbox selects the current page.
- **Select all:** After a page select, show a "Select all 4,000 matching" link. Selection then applies to the filter, not the loaded rows.
- **Action bar:** When anything is selected, show a bar with the count and actions. Keep selection across pages and filter changes.
- **Mark paid:** Run it immediately and show an Undo toast.
- **Reminders:** They can't be unsent, so confirm with the count and recipients.
- **Failures:** List any rows that failed.
