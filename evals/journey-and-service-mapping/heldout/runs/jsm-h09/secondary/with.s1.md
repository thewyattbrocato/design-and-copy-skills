Run it in order: correct the map, vote on moments, then rate how well each stage is supported. Expect pushback from whichever team the pain points point at.

**Exec: 10 minutes, three slides**

1. **Frame:** the person, start and end, the decision you need from them, and the status line. Add one number if you have it, such as time from contract to first payroll run. If you don't, put `[to measure]`, not an estimate.
