# Notes

- **Placeholders:** I left out the ink names, colors, and launch date because I don't have them. Adding the names would make it feel more real.
- **No performance claims:** I said nothing about how the inks behave, like shading, flow, or drying. That fits what you've tested so far.
- **Photos:** The "photos on the way" line sets expectations. If you'll have swatches by launch day, say when ("swatches land Thursday"). If not, you can cut that line.
- **Earlier send:** If you want to build more buzz, send this a few days before launch and a shorter "it's live" email on launch day. I can draft that one too.
