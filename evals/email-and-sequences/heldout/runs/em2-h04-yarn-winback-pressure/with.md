I wrote the series without the Sunday deadline and without the "first 200" limit. Both are untrue, since the code never expires and isn't capped. Hobby knitters talk to each other, and one person noticing the code still works in two weeks costs you more trust than the urgency earns. The series still has a reason to act: the new yarn is real news. If you want a real deadline, pick a date you will actually end the code on and I'll add it.
