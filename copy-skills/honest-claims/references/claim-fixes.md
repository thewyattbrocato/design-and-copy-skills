# Claim fixes

Load when a draft carries a device from the left column below, when asked to write customer proof, or when copy touches a high-risk category. Every example is invented and generic.

## Device, then its honest form

| Device | Honest form |
|---|---|
| Timer or "only a few left" with no cause | The real cause and exact end ("price changes on the 1st"), or the true cost of waiting, or nothing |
| "N people viewing now", "N booked today" with no live data | A current, sourced count with its basis, or a benefit line |
| Fake progress steps or an artificial wait | Real stage names, or a plain "working" message |
| "Was $X" never charged | The price charged before, or the value in use (cost per use, savings the reader can work out) |
| "Trusted by thousands" | "Used by 1,200 clubs since 2023" only if the user gave it; otherwise a placeholder or no line |
| "Most popular" with no data | "Good for small teams" with the reason, or none |
| "Doctors recommend", "studies show" | The named source and its scope, or the plain claim the user can back |
| "Industry-leading" | What it does, measured if known |
| Comparison table that wins every row | Real rivals, same dimension, dated, with their strengths |
| Benefit line drifting into an outcome ("clear all your debt") | The capability and its condition ("a plan that shows each payment and its end date") |
| Asterisk or fine-print retraction | The condition in plain text beside the promise; if it cannot be said plainly, drop the promise |
| Button that pays but says "Next" | Name the consequence and show the total first |
| Decline link that shames ("No, I like paying more") | A neutral decline ("Not now"); the offer's value carries the click |
| Ad made to look like news or official mail | Match the host's quality, but label it clearly |
| Fear with an invented statistic | The documented risk at true size, plus the step to take |

## Customer request message

When asked for testimonials the user does not have, deliver this instead (short, in the user's language):

> Hi [name], we're collecting a few words from customers. Could you answer any of these in a line or two? What were you doing before? What was frustrating? What changed? When did you notice it working? How is it now? We'll only publish what you approve, with your name and role if you're happy for us to.

Then placeholders where the quotes go: `[approved quote, name, role]`. If the user gives quotes later, trim but never reword; disclose any incentive.

## High-risk categories

Health outcomes, earnings and savings, safety, environmental benefit, children, "guaranteed", "#1", "only", "first" and any named rival. Use the user's facts with their scope, and add one line: "have this claim checked before publishing". Outside rules differ by place and change; describe them as external and current, never quote them.
