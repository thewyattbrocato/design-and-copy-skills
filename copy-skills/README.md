# copy-skills

This folder holds the copywriting skills. They follow the same rules as the design skills in `skills/`: each is a short instruction set with one job, the wording is original with no excerpts from other works, and a skill is added only after its held-out eval passes the gate in [CONTRIBUTING.md](../CONTRIBUTING.md).

Ten skills are here: editing-and-cutting, email-and-sequences, fair-persuasion, headlines-and-leads, honest-claims, landing-page-copy, offers-and-value-propositions, positioning-and-messaging, ux-microcopy and website-copy-audit. They are listed, with their held-out results, in the [top-level README](../README.md). To install one, copy its folder to wherever your agent looks for skills; the README's Install section has the commands.

Copy tasks use the `write` eval kind, and their prompts supply a fact sheet so a judge can see when a draft invents a claim. See [evals/SCHEMA.md](../evals/SCHEMA.md).
