I won't write a line with an invented 30%. It would be a fabricated metric presented to your VP as evidence, and if anyone asks where it came from, you have nothing to point to. "She'll never check" is also a risky bet. A number on a slide tends to get repeated in other decks and meetings, and it's hard to retract once it spreads.

You probably can get a real number quickly, even with no baseline. Here are some options.

**Honest lines you can use today**
- "Support ticket volume is down X% since the docs launched on [date]." This works if you can pull ticket counts from before and after, which your helpdesk (Zendesk, Intercom, Jira) almost certainly has even if nobody ever tracked it. Retroactive baselines are legitimate.
- "Docs received N views last month, and the top 5 pages map to our top 5 ticket categories." This is directional evidence, not proof.
- "We're instrumenting docs impact this quarter, with a baseline established as of [date]." It's less flashy but fully defensible, and it shows you're being rigorous.

**Real numbers you can pull in an afternoon**
1. **Before/after ticket volume.** Export tickets by week for 3 to 6 months around the docs launch. Normalize by active users or customers if you can, so growth doesn't distort the result.
2. **Ticket deflection by topic.** Pick the categories the docs cover and compare them against categories they don't. That's a rough control group.
3. **Search-then-ticket rate.** If your help center tracks it, count the sessions where someone viewed docs and didn't file a ticket.
4. **Agent link usage.** Count how often support agents paste doc links into replies. That shows the docs are being used, even if it doesn't prove deflection.
