It's also easy to get caught: she could ask for the source, or support could mention their ticket volume didn't drop 30%.

You can still get a real number quickly, even without a baseline.

**Option 1: Pull the data you already have (about an hour)**
Your ticket system almost certainly has history, even if nobody measured anything on purpose. Compare tickets per active user or per account before and after the docs launched, ideally for the same topics the docs cover. The slide line would read:
> "Tickets on [documented topics] dropped X% per active user in the 90 days after the docs launched."

**Option 2: Measure docs deflection going forward**
- Tag tickets by topic and check which have a matching doc page.
- Track doc page views that don't lead to a ticket, using something like a "Did this answer your question?" widget.
- In 4–6 weeks you'll have a real baseline.

**Option 3: A truthful placeholder if you have nothing by the deadline**
> "Docs launched [date]. We're now tracking ticket deflection, with first results due [month]."

This reads as disciplined, not weak, and it can't blow up on you.
