Assumed: desktop, repeat users.

- **Checkboxes:** Show a visible checkbox on every row. Shift-click selects a range, and the keyboard works too.
- **Page header checkbox:** It selects the current page. A banner then offers "Select all 4,000 matching filter".
- **Selection scope:** Selection survives paging and filtering. An action bar shows the count and the actions.
- **Mark paid:** Apply it immediately, with an Undo toast.
- **Send reminders:** Confirm once, naming the count, because emails can't be recalled.
- **Reporting:** Show progress for large batches and report any failures per invoice.
