Assumed: desktop, frequent use.

- **Checkboxes:** Show a visible checkbox on each row. Shift-click selects a range. The header checkbox selects the current page.
- **Select all:** After a page select, show "Select all 4,000 matching filter" so people can select across pages. Selection survives paging and filtering.
- **Action bar:** Once something is selected, show a bar with the count, "Mark paid" and "Send reminders". Esc clears the selection.
- **Mark paid:** Undoable with a toast. It has no confirmation unless it moves money.
- **Reminders:** Reminders can't be unsent, so confirm once with the recipient count.
- **Large jobs:** Run them in the background with progress and per-invoice failures.
- **Accessibility:** Make everything keyboard-accessible.
