Assumed: desktop accountants, daily use.

- **Checkboxes:** Show a visible checkbox on every row. Shift-click selects a range, and the keyboard works too.
- **Select-all:** The header checkbox selects the current page. Then a banner offers "Select all 4,000 matching," because filtered sets are the usual case.
- **Persistence:** Selection survives paging, sorting, and filtering. A sticky bar shows the count, "Mark paid," "Send reminders," and "Clear."
- **Scope:** "Select all" selects the filter, not fixed rows. Show the exact count before acting.
- **Mark paid:** Run it immediately and offer Undo for about 10 seconds. It's reversible, so don't ask "Are you sure?"
- **Reminders:** These can't be unsent, so confirm once with the count and a preview.
- **Progress:** Run large batches in the background. Show progress, then per-invoice failures with a retry.
