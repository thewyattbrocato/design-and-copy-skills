**I recommend the first option: make the special's row bold, and add a small "Special" label as a second cue.**

The page has only five rows, and one of them is the special. Highlighting one row in five is about 20% of the table, which is already above the roughly 10% an emphasis budget should spend. So the treatment should be quiet.

- **Bold row (recommended).** Weight is the cheapest and strongest way to rank items inside a fixed table order. It still reads in grayscale and when printed. It also matches the tone of a school menu, which should be calm and scannable. On its own, though, bold only tells people the row is different, not why. Adding a small "Special" label (option 3's idea) fixes that and means the row doesn't rely on weight alone. Bold plus label is still one technique, applied once.
- **Yellow box with a star.** This is the loudest option, and it has three problems. The box and star do the same job twice. A bright yellow fill competes with the day and the menu text for attention, and it would be the only colored block on a plain page. Dark text on bright yellow is fine for contrast, but the star is decoration, so it should go unless the user wants a festive look.
- **Label only, uniform table.** This is the safest choice, but it's too weak. A small label in a uniform table is easy to miss, so the special wouldn't stand out.

**Implementation notes**
- Use semibold or bold on the main and side text in that row. The day name can stay at its normal weight so the row doesn't become heavier than the headings.
- Keep the "Special" label small and put it in the same place every time, for example just before or after the main dish name. Make it text, not a colored badge.
- If you want a little more separation, add a little extra space around that row. Don't add a fill.

If your teammate wants something more celebratory, such as a seasonal menu, I'd use a light tinted row background in place of the bright yellow box and drop the star. Keep the bold and the label.
