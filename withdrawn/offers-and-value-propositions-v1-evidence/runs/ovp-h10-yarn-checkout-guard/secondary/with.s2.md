**Cut these:**
- **Company name** — irrelevant for yarn subscriptions
- **How did you hear about us** — ask via post-purchase email instead (higher response, lower friction)
- **Create password** at checkout — offer it post-purchase or skip entirely if they only buy once

**Consider optional/collapsible:**
- **Phone number** — useful for shipping issues, but make it optional or ask only if needed

**Reorder like this:**
1. **Email** (top—friction-minimal, clearly needed)
2. **Full name** (shipping requirement, quick)
3. **Shipping address** (essential, gets you to the goal)
4. **Billing address** (with checkbox: "Same as shipping" to skip if possible)
5. **Promo code** (goes here to incentivize before the ask, not bury it)
6. **Card details** (last thing before submit—they're committed by then)

**Fix the error message immediately:**
"Error 402" is a raw HTTP status code. Replace it with: *"Card declined. Please try another payment method or contact your bank."* Add a retry button and maybe mention common reasons (insufficient funds, expired card, incorrect CVV).

The core issue: you're asking for 9 pieces of info before payment. That's a lot of friction for people buying a *subscription*—they're already committing to recurring charges. Trim ruthlessly and you should see abandonment drop noticeably.
