**Pick: a modular grid**, built on a 12-column base (4 columns on tablet, 1 on mobile).

**Why not the others**
- A single narrow column reads well for stories but will make six sections feel monotonous. Statistics would have nowhere to go except inline, where they get lost.
- A two-column layout handles long text well, but it's rigid. Stats and pull quotes end up squeezed into a column or breaking the flow.
- A modular grid lets you vary the rhythm between text, numbers, and stories while keeping one underlying structure. For a report with this mix, that flexibility matters most.

**How I'd use the grid**
- **Long text:** Set it across 6–8 of the 12 columns, about 60–75 characters per line, with the remaining columns left as margin or used for sidenotes. Don't run body text across the full grid width.
- **Stories:** Give them a distinct treatment. Use a large photo spanning 5–6 columns, a pull quote, and the narrative in a single readable column. This signals "human moment" versus "data moment".
- **Section openers:** Use the full width for a big title, a one-line summary, and one headline number.

**How I'd handle the stats**
1. **Lead with one hero stat per section.** Show it very large, 3–4 columns wide, with a one-line plain-language label ("12,400 adults gained reading confidence"). Don't give every number the same weight.
2. **Group the supporting stats into a row of 3–4 modules.** Each module holds the number, a short label, and a year-on-year comparison where it helps. Keep them visually identical so they're easy to scan.
3. **Use charts only when there's a comparison or trend.** A single figure doesn't need a chart. A trend over several years or a before/after does. Keep these simple: one message per chart, direct labels, no legends where possible.
4. **Tie numbers to people.** Put a stat next to the story it relates to, such as "1 in 6 adults struggles to read" beside a learner's account. This is the strongest way to make the data land for a charity audience.
5. **Keep the styling consistent.** Use the same number typeface, size scale and accent colour for stats throughout, so readers learn to spot them immediately.
6. **Add context.** Give a source or a year for each figure, and put the methodology in a small footnote or an appendix rather than in the main flow.

**Practical notes**
- Build 4–5 reusable modules (hero stat, stat row, story spread, chart block, text page) and combine them. This keeps six sections coherent and makes production faster.
- Check accessibility: sufficient contrast, readable sizes (body 10–11pt in print), and alt text if there's a web version.
