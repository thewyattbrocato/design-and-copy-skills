Break the grid only when you can name the job the break does. If you can't say what it's for, keep the element on the grid.

## When it's a good idea

| Job | Example |
| --- | --- |
| **The image is the page** | A full-bleed photo at the top of a feature story or product launch. It runs edge to edge while the text below stays in its column. |
| **Pull a quote out of the text** | A pull quote hangs into the margin, or is set larger and offset from the column, so it works as an entry point into a long read. |
| **Mark the one odd item in an obedient set** | In a row of equal cards, the featured or sale item is wider, taller, or offset. The set is regular enough that the exception reads as meaningful. |
| **Give wide content room** | A figure, wide table, code block or diagram is wider than the text column. The prose keeps its 60–70 character measure while the figure gets the space it needs. |
| **Make a single moment loud** | One section in a long page, such as a big statement, a tilted badge or an oversized number. The other sections stay calm so the loud one registers. |
| **Expressive work** | A poster, magazine opener or portfolio piece where the break is the point. Even here, keep a clear entry point and keep the key facts findable. |

## How to keep it from looking like a mistake

1. **Establish the grid first.** A break only reads as deliberate against a visible, consistent structure. If the layout is already loose, the break looks like one more misalignment.
2. **Go far enough.** Overshooting a column edge by a few pixels looks like a bug. Break by a whole column or margin, or go fully to the viewport edge.
3. **Align to something.** The broken element should still share an edge with something else, such as the image edge, a heading, or the next section's offset. It should leave the grid, not float free.
4. **Break rarely, and each time for a different named reason.** If the same break shows up three times, it has become a rule. Build it into the structure instead.
5. **Keep the entry point and primary action clear.** Overlaps, rotations and bleeds shouldn't bury the headline or the call to action.
6. **Don't crop or collide with content.** Text shouldn't run under an overlapping image. Whole images stay whole.
7. **Plan the narrow screen.** Hanging quotes and offsets usually have to collapse into the column on a phone. Check that the stacked order still reads correctly and nothing overflows sideways.
8. **Test with real content.** A break that works with your demo headline can fail with the longest title or a translated string.

## Quick test

Say the job in a phrase, for example "the photo is the page" or "this quote is the way into the article". If you can, keep the break and check the points above. If you can't, move the element back onto the grid.
