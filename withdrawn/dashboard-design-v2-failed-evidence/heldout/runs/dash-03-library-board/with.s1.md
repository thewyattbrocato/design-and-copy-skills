**Leave these off**

- **New cards issued:** it's noisy month to month, and cardholders (#4) already tells the story.
- **Computer/wifi sessions:** it's useful for staff, but the board won't act on it. Put it in your narrative if it changes sharply.
- **Social media followers:** it doesn't show service or finances.
- **Cost per visit:** it swings with door-count quirks, and a volunteer will read it as a verdict on efficiency. Budget vs plan answers the money question more directly.
- **Volunteer hours:** it's good for a thank-you, not a decision.
- **Items per capita:** it changes slowly and matters mostly for state reports. Show it once a year.
- **Overdue items out:** it's an operational detail for staff.

**Design notes**

- **Compare to last year, not last meeting.** With six meetings a year and seasonal swings (summer reading, winter lulls), "vs the same two months last year" is the fair comparison. Last meeting's number will mislead.
- **Show the gap in words.** Write "Visits up 6% vs last year", not two totals to subtract.
- **Put exceptions first.** Holds and budget are where the board might act, so give them top placement if either is off. Show the others as quiet cards.
- **Group by the board's two questions.** Use a "Serving the town" group (#1–5) and a "Money" group (#6–7).
- **Branch detail goes a level down.** Show system totals on the page and keep the four-branch breakdown in an appendix. If one branch is the reason a number moved, say so in one line.
- **Budget gets a bar.** Show a bar with a marker for where plan says you should be today. Avoid a gauge.

**Two things I need from you, which I haven't guessed**

- The holds target (for example, "no more than N waiting over 14 days"). Until you set one, show the count with "target: set by board".
- The town population figure you want to use for cardholder share.
