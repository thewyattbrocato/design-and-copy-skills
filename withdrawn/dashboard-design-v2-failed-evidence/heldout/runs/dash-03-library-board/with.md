**Leave off**
- **3. New cards:** it's mostly covered by cardholders. Keep it in your staff report.
- **6. Computer/wifi sessions:** useful for operations, but it doesn't change a board decision. Add it back if digital access is a board priority.
- **9. Social followers:** vanity metric, so it doesn't answer "are we serving the town?"
- **11. Volunteer hours:** a nice story for your narrative, not a dashboard number.
- **12. Items per capita:** changes once a year, so it belongs in the annual report.
- **13. Overdue items:** an operational detail. Holds waiting is the better service signal.
- **14. Donations:** leave off unless the budget depends on them. If it does, fold them into the budget line as "revenue vs plan" instead of adding a tile.

**Design notes**
- **Compare to last year, not last period.** Library use is seasonal, and a July–August versus May–June comparison will mislead a board. Use the same two months last year.
- **Show the gap in words.** For example, "Visits up 6% vs last year" or "Budget $12K under plan". Don't make volunteers subtract two totals.
- **Use total cardholders with a caveat.** Total registered cardholders includes stale cards. If you can get "active in the last 12 months", use that instead, with the same population comparison.
- **Order the page by what needs attention.** Put money and holds at the top, then the four service measures. Anything off-track should be the loudest thing on the page, and healthy items should stay quiet.
- **Show all four branches in one line.** Keep the page to system totals, with branch detail in a backup sheet in case someone asks.
- **I haven't set any targets.** Holds needs a target the board picks, and budget needs your plan's phasing. I'd rather leave a slot marked "target: set by board" than guess.
