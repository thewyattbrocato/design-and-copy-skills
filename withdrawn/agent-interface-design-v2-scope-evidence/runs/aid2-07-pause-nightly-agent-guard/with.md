Pause should stop the agent at a safe checkpoint, not mid-write. It should finish or roll back the in-flight transaction, then hold. It should record where it stopped and show "Paused, N items unreconciled" instead of looking idle. Resume should continue from that checkpoint and re-check feed and ledger state, since either may have changed. Nightly runs should be skipped or queued, depending on a setting, and the user should be alerted if the pause causes a missed close deadline.
