Pause should stop the agent cleanly at a safe checkpoint, not mid-transaction. It should finish or roll back the current batch, record the position (feed, cursor, matched/unmatched state), and block new runs and ledger writes. Resume should continue from that checkpoint, idempotently, without double-posting. The UI should show paused state, the pause's author, and any missed schedule, and it should alert if the pause stretches past the close deadline.
