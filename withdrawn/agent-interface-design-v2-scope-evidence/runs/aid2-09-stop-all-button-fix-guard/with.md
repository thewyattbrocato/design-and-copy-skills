Add a confirmation step to "Stop all agents", and make the dialog specific. For example, the title would read "Stop all 12 running agents?" and the buttons would read "Stop 12 agents" and "Cancel". Cancel should be the default focus.

Restyling or moving the button would make a misclick less likely, but the click would still go straight through. A confirmation catches the mistake even when the click was an accident. Stopping every agent is rare and high-impact, so the extra click is a fair cost. It's also the action you'd least want to fire by accident.

The specific wording matters because a generic "Are you sure?" gets clicked through by habit. Naming the consequence and the count makes someone who wanted Refresh notice the mismatch.

If you have room for a second tweak later, make the stop button red and put some space between it and Refresh. The 40 minutes it took to notice is a separate gap, which a "N agents stopped" banner on the dashboard would close.
