**Pick: a modular grid, built on a reading column. It isn't a uniform multi-column grid.**

The report mixes long text, stats and stories, and each needs something different. A single narrow column would make the stats feel like an afterthought. A two-column text layout would force long prose, pull-quotes and big numbers into the same two tracks. A modular grid lets each kind of content have its own structure. The material is a mix, so each section gets a structure that fits it.

**How I'd set it up**
- **Grid:** Use a 12-column grid as a planning sketch. Body text never spans more than about 6–7 columns, which keeps lines around 60–70 characters. Narrative text sits in that capped column. Stats, images and pull-quotes use the remaining columns, or the full width.
- **Secondary column:** Give captions, sidebars and small notes a narrower column beside the text. It should be about half the width of the main column.
- **Pacing across the six sections:** Don't use the same template six times. Alternate calm text-led sections (one reading column, lots of white space) with denser ones (stats band, story with a large photo). Make one section the loud one, such as the headline impact section. Keep the others quieter.
- **Print or PDF:** If this is a fixed-size document, the columns, gutters and margins have to add up exactly. Keep key text out of the trim and bleed areas. If it's a web page, make the grid fluid, with the modules stacking into one column on a phone.

**Handling the stats**
- **Lead with a few headline numbers.** Pick 3–4 per report, set very large (for example "12,400 children reached"), each with a one-line plain-language label. Put them in a full-width band at the start of the relevant section, or in the opening spread. Don't scatter them through paragraphs.
- **Use a stat band, not a card row.** Make the numbers equal-width modules on the grid, aligned to the same edges as the text above and below. Vary the pattern between sections so it doesn't become a repeated three-icon-card strip.
- **Put supporting numbers in the margin or the secondary column.** Smaller figures (percentages, year-on-year change) can sit beside the prose they support. A reader then sees the number next to the claim it backs up.
- **Chart only what needs comparing.** Trends over time or a breakdown by region get a simple chart, one per idea, labelled directly. A single figure like "87% improved reading level" is better as a big number than a pie chart.
- **Pair at least one stat with a story.** For example, put "1 in 5 adults struggle to read" beside a short learner story. The number gives scale, and the story makes it personal. This is what makes charity reports persuasive.
- **Give every number context.** Say what it's compared to (last year, the target) and what period it covers. Keep the number formatting, units and rounding consistent across the report.
