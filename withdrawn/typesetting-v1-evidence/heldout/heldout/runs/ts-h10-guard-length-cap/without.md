**Statement screen: type and spacing**

Use the platform system font (SF Pro / Roboto) with Dynamic Type/font scaling supported throughout. Use a 4pt base grid, 16pt screen margins.

- **Balance:** Largest element, ~34pt semibold, with a small 13pt secondary-color "Current balance" label above it. Leave 24pt below before the list.
- **Transaction rows:** 16pt vertical padding, 1px hairline dividers. Merchant is 16pt regular, left-aligned, and truncates to one line. Date is 13pt secondary beneath it. Amount is 16pt medium, right-aligned, with tabular figures so decimals line up.
- **Credits:** Marked with a "+" prefix and a green tone, never color alone. Debits stay in primary text color.
- **Month grouping:** Sticky 13pt semibold headers with 24pt space above.
- **Footnote:** 12pt minimum, secondary color, 1.4 line height, 32pt above and below, at the end of the list.
- **Accessibility:** Meet WCAG AA contrast (4.5:1) and 44pt minimum row tap targets.
