**Statement screen type and spacing**

Anchor: a clean, calm product interface. Use the system font and size everything in scalable units (iOS Dynamic Type, Android sp) so it follows the user's text-size setting.

- **Balance:** 34pt semibold, tabular figures. A 13pt "Current balance" label sits above it in sentence case. Leave 24pt below it.
- **Rows:** merchant at 17pt regular, with the date beneath at 13pt in secondary gray. Amount at 17pt, right-aligned, with tabular figures and two decimals on every row. Rows get 12pt vertical padding and a hairline divider.
- **Credits:** show a true minus sign on debits and a "+" on credits, in a distinct color. Don't rely on color alone.
- **Section header:** "October" at 13pt semibold, with 24pt above and 8pt below.
- **Footnote:** 13pt (never below 12pt) at 1.4 line height, flush left, 24pt above it. The overdraft fee wording must stay readable, so don't shrink it further.

Sizes: 34, 17, 13.
