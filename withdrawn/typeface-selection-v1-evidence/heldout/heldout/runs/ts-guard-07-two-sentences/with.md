The system font stack is fine for a developer docs site. On laptops, San Francisco, Segoe UI and the system monospaces (SF Mono, Consolas, Menlo) render crisply, load instantly, and are what developers already read all day. A paid font mostly buys brand personality, so if you want some, use a free, well-hinted web font like Inter for prose or JetBrains Mono for code, rather than paying.
