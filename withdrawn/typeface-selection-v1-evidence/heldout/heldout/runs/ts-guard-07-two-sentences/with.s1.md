The system font stack is fine, and for developers on laptops it's a good default. It renders instantly, looks native, and Apple, Windows and Linux all ship solid monospaces (SF Mono/Menlo, Consolas, DejaVu Sans Mono). Paying for a font only buys brand character, so it's worth considering only if the brand needs that. If you want one upgrade, a free open-license web font for the headings or code would do it, and the system stack stays as the fallback.
