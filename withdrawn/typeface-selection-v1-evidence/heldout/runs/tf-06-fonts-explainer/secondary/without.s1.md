**What a variable font is:** A normal font comes as separate files for each style: one for regular, one for bold, one for italic, one for light, and so on. A variable font packs all of those styles into one file, and the styles can blend smoothly between each other. Instead of picking "Medium" from a list, a designer or website can set any weight in between, or adjust width or slant, using a dial. Think of it as one adjustable font instead of a box of separate ones.

**Is it better?** It depends on what you need.
- **Better** if you want many weights or styles, or fine-tuned in-between looks. One file can replace several, and the page can load fewer files.
- **Not necessarily better** if you only use one or two styles. A regular font file is simpler and works everywhere. Either choice is fine for a bakery site, and the designer chose this one for a reason, so it's reasonable to use it.

**Are you allowed to put it on your website?** Maybe, and this is the part to check. Fonts are licensed software, and a license for installing a font on a computer (for printing or design work) is often different from a license for using it on a website. Before you publish:

1. **Ask your designer for the license.** Ask: "Does the license allow web use, and can I host it on my own site?" Designers usually buy fonts from a foundry, and many licenses have a separate "web" or "webfont" option.
2. **Check whether it's free for web use.** Some fonts use the SIL Open Font License (OFL), which allows free web use. Google Fonts are also free for websites. If the designer made the font, they can give you permission in writing.
3. **Ask about the file format.** A `.ttf` file is meant for desktop use. Websites usually use a `.woff2` version, which is a conversion of the same font. Some licenses restrict converting, so confirm that's allowed too.
4. **Get the answer in writing.** An email from the designer confirming the web license is enough for a small business.

If the license doesn't cover websites, the usual fix is to buy a web license from the font's foundry, which is often inexpensive for a small site. Don't upload the file to your site until you've confirmed this, since using a font without permission can cause problems later.
