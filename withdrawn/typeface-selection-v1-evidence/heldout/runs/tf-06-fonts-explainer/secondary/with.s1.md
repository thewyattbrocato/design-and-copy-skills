**What a variable font is:** A normal font usually comes as separate files for each style: Regular, Bold, Italic, Light, and so on. A variable font packs all of those styles into one file, with dials for weight, width, slant, and similar settings. A designer can set any point along a dial, such as "weight 450," not just the fixed steps.

**Is it better?** Not automatically. It's more flexible, and if you use several weights or styles, one file can be smaller than loading five or six separate ones. If you only use Regular and Bold, a normal font is just as good. What matters for your site is how the designer uses it, and whether the file is loaded efficiently.

**Can you use it on your website?** Maybe, and you need to check. Font licenses are separate from the file. A font you can install on your computer is often licensed only for that. Using it on a website usually needs a web license, and some licenses limit the number of visitors or pageviews. Your designer may have bought the font, or it may be free under a license like the SIL Open Font License, which generally allows website use. The `.ttf` file alone doesn't tell you which.

**What to do:**
1. Ask your designer: "Is this font licensed for web use on my bakery's site, and do you have the license terms or receipt?" If they bought it, they can usually tell you what you're allowed to do.
2. If you want to check yourself on a Mac, open the file (double-click it), and Font Book will show a copyright or license note.
3. If the license doesn't cover web use, you can buy a web license from the foundry that made the font, or pick a free alternative. Google Fonts has many, and they're free to use on websites.

Your designer will probably handle the technical part of adding the font to the site. Your main job is to confirm the license covers your use.
