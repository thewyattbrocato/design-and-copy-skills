The footer feels glued on because nothing separates it from the content. Its margin is 0, and the only space above it is the last section's 8px bottom margin, which is smaller than the footer's own 24px side padding, so the gap reads as a seam instead of a break. The single fix is to give the footer a larger top margin from the spacing scale, such as `footer { margin: 32px 0 0; }`. That puts the footer's separation above the 24px `main` padding and the 8px gaps between sections, so it reads as a different region.
