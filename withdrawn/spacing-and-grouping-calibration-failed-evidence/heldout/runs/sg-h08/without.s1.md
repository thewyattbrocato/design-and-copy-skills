The footer has `margin: 0`, and the last section above it only has an 8px bottom margin. That margin is the only space between the content and the footer's top border, so the border sits almost on top of the content. The main element's 24px padding doesn't help, because it is inside `main` and the footer comes after it. The single fix is to give the footer a real top margin, for example `footer { margin: 32px 0 0; }`.
