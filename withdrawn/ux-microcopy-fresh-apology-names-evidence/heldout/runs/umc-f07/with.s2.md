**Notes**
- I used "Error:" with no count because the fact sheet doesn't say how many errors the summary will list. If the build can count them, "2 errors: Step 1 of 3: …" is more useful, but only if the number is accurate.
- Check your answers and Application sent have no step number because they aren't among the three steps. Each title starts with words specific to that page and ends with the service and council names, so the page is still identifiable if the tab truncates the end.
