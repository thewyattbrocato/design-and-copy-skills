Decisions to confirm

These are judgment calls made while consolidating. Please check each one.

  1. Near-duplicate colors were merged into the most frequent value. If any pair was intentionally different, say so.
  2. Sky (#2A8BD1) is for non-text use only because it's too light for small text on white.
  3. Input borders use Muted instead of Line for contrast. This is slightly heavier than what's likely in the CSS today.
  4. Badges are tinted with dark text, not solid color with white text. White on Success is 4.2:1 and on Warning is far lower, so they'd fail contrast.
  5. Collapsing 15px and 17px to 16px, and 5px/6px to 4px, will shift some layouts by a pixel or two.
  6. No dark theme is defined. Tell me if the deck app needs one for night sailings.
