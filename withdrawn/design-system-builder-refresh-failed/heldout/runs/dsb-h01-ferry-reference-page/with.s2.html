How to read this. Everything here was built from the extracted value lists you sent, not from the stylesheets or screens themselves. Merges are proposals. The status tints, the 56px deck control height and the hover and pressed treatments are new; the CSS has nothing to map them to. Contrast figures are hand-calculated and approximate, so re-run them in a checker before you sign off.

Principles

Ranked. When two conflict, the higher one wins. Each has a test anyone can run.

1. Readable at a glance

Deck crew read this standing up, often outdoors. Times and status are the largest, clearest things on a sailing.
Test: squint at a screenshot; can you still tell the time and status?

2. Never color alone

Status always has a word and a shape as well as a color.
Test: view in grayscale; all three statuses still differ.

3. One value per job

A new color, size or spacing replaces or merges with an existing one. It is not added beside it.
Test: a pull request that adds a value names the one it replaces.

Changing the system

Adding something

A new component or value is added when a second screen needs it and no existing one can be adjusted to fit. Otherwise it stays local to its screen and is marked as an exception in the code.

New components must show every state (default, hover, pressed, focus, disabled, loading, error where relevant), the long-text case, and the empty case.

Changing or removing

Four kinds of change: add, modify, deprecate, remove. Deprecate first, tell the people using it, give the replacement, then remove. Keep a one-line changelog entry for each.

Owner: [name]. Source of truth: the tokens block at the top of this file, until both products read it from one shared file.

Don’t: add a gray “just a bit lighter”; write a hex value inside a component; show status by color alone; make a second sailing card for the tablet. If the tablet needs more, add a size to this one.
Not covered yet: dark mode, forms with several steps, modals, toasts, icons beyond the three status ones, and any motion beyond the loading spinner. None of them were in the list you sent.
