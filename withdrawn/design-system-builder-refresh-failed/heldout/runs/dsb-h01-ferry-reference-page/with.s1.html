Marlowe Ferries Style Guide

The small set of colors, type sizes, spacing, radii and components that the booking site and the deck-crew tablet app should share.

Built from the extracted CSS values you supplied: 22 colors, 14 font sizes, 17 spacings and 7 radii. They are cut to 12 colors, 6 type sizes, 8 spacings and 4 radii. Every old value maps to one token in the "Replaces" columns below. Assumptions: web and tablet share one brand and one light theme, and a small team owns this. Usage counts per value aren't shown because the extract gave order only. Contrast ratios quoted here were calculated by hand from the hex values, so re-check them with a tool before sign-off.

Principles

  • 1. Readable at arm's lengthDeck crew use the tablet standing, in glare. Test: tablet controls are 48px tall, and status is never shown by color alone.
  • 2. Conventional where money and schedules are involvedBooking and departure screens use familiar patterns. Test: a new customer completes a booking without learning anything.
  • 3. One value per jobIf two values are within a step of each other, they are one token. Test: no two neighbors in any scale are easily confused.

Contrast notes

  • White on color-action is about 5.4:1 and white on color-danger about 5.4:1, so both pass for text.
  • color-text-secondary on white is about 4.6:1 and passes. On color-surface-page it is about 4.3:1, so don't use it for small text directly on the page background; put it on a white card.
  • color-success on white is about 4.2:1 and color-warning is much lower. Neither is used as text. They are small markers next to a dark text label.
  • The old #7a8794 was about 3.6:1 on white and failed. Folding it into #6b7785 fixes that.
  • Input borders use color-border-control (about 4.6:1) so fields are visible. color-border-subtle is for decoration only.

Decisions for you

These merges were judgment calls. Change any of them before this goes out.

  • Type 13, 18, 28 and 40. 13 went to 14, 18 to 20, 28 to 32. 40 went to 32 as well, so the old hero size is gone. If you need a bigger hero, add one display size above 32 and nothing else.
  • Spacing 6, 10, 14, 20, 28 and 40. 6 and 10 went to 8, 14 to 12, 20 to 24, 28 to 32, 40 to 48. Expect some layouts to shift by 2 to 4px.
  • Status colors. Green and amber are markers only, never text, because of contrast. If you want colored badge backgrounds, new tint values would be needed and checked.
  • Dark theme. There isn't one. Because components use roles, a dark theme later means remapping the role values, not inverting them.

Keeping it honest

  • One source. Put the :root block of this page into one tokens file that the booking site and the tablet app both import. Any difference between them is a bug.
  • Adding a value. New values replace or merge with an existing one. A genuinely new one needs a reason written next to it.
  • Adding a component. It must be needed by a second screen, and it ships with all of its states and edge content.
  • Changing or removing. Four change types: add, modify, deprecate, remove. Announce a deprecation, keep the old name working with a pointer to the new one, then remove it.
