Marlowe Ferries front-end styles

Proposal v0.1 for the booking site and the deck-crew tablet app. Built from the values currently in the CSS: near-duplicates are merged, and every value that remains has a role. Colour values below are proposals taken from your existing palette. Text and background pairs were chosen for contrast but have not been run through a checker, so verify before sign-off.

Principles

1. Readable at arm's length, in glare. Deck crew use the tablet outdoors, so text stays at 14px or larger except captions, and every tap target is at least 44px.
2. Status is never colour alone. Every status carries a symbol and a word.
3. One value per job. If two values look the same, they are the same token.
