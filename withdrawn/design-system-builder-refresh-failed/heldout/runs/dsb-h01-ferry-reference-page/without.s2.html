Marlowe Ferries Style Guide

One set of colors, type sizes, spacing and radii for the booking site and the deck crew tablet app. This is a proposal: it reduces the ~80 values currently in the CSS to a small set of tokens. The final section lists what each old value maps to.

Color

Twelve colors. Navy is the brand and the default for primary actions. Blue is for links and hover. Status colors are always paired with a text label and a shape, never used alone.

Brand

Navy#0B3C5DNav bar, primary button, headings, key numbers.
Blue#1D6FA3Text links, primary button hover, focused input border.
Sky#2A8BD1Focus rings, nav hover underline, chart/accent fills. Not for text on white.

Neutrals

White#ffffffCards, inputs, text on navy.
Surface#f4f7faPage background.
Tint#e8f1f8Hover and selected backgrounds.
Line#d7dee5Dividers, card borders, disabled fills.
Muted#6b7785Secondary text, placeholders, input borders. Darkest of the two greys so it passes contrast on white.
Ink#1a1a1aBody text.

Status

Success#1e8e5aOn time. Indicator dot and border only.
Warning#f2b84bDelayed. Indicator dot and border only; never text.
Danger#c0392bCancelled, errors, destructive actions.

Typography

System font stack, so each device uses its own native face. Eight sizes. Body text is 16px; nothing smaller than 12px, and 12px is for captions and badges only. Crew tablets should stay at 16px or above for anything they need to read at arm's length.

Spacing

A 4px base with eight steps. Use these for padding, margins and gaps. Inside a component, use 4–16. Between components, use 16–32. Between page sections, use 48–64.

Corner radius

Four values. Rounder means bigger or more self-contained.

Components

All interactive controls are at least 44px tall so they work with gloves on the tablet. Every control has a visible focus ring.
