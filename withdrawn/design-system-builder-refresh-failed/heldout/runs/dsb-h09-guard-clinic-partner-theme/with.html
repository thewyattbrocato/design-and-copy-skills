What changes for Halden

ElementKestrel defaultHalden
Main (brand) color #2F6FED #F5C842
Headings #14213D #1F4D3A
Text on brand-colored buttons #FFFFFF #1F4D3A
Outline button text & border #2F6FED #1F4D3A

Two adjustments keep Halden's yellow readable: white text on #F5C842 is hard to read, so text on yellow buttons uses the dark green. Yellow outlines and text would also be faint on white, so outline buttons use the dark green. Page background, card surface, borders, body text, and corner radius are the same as the default.
